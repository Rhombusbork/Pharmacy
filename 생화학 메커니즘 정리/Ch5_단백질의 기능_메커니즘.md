# A. 리간드 결합의 원리

## 1. 리간드 결합의 원리
**출처** (08 · 19:03 ~ 24:49) ★★

- 효소 단백질: 기질의 공유 결합을 바꿈 / 비효소 단백질(호르몬, 운반체, 액틴·마이오신, 항체, TCR): **결합**으로 기능.
- 리간드 결합은 **가역적**(결합·해리), **특이적**, 원리는 **상보성**.
- 단백질은 고정되지 않고 **유연**(진동) → 리간드가 오면 거기에 맞춰 움직임 = **유도 적합(induced fit)**. 열쇠-자물쇠가 아님.
- 다중 소단위체 단백질은 서로의 형태 변화를 유도(→ 헤모글로빈 협동성).

## 2. Kd와 친화도
**출처** (08 · 35:17 ~ 46:29) ★★

- P + L ⇌ PL, Ka(결합 상수, M⁻¹) — 여기서 Ka는 산 해리 상수가 아님. **Kd = 1/Ka**(단위 M).
- **θ(Y) = [L] / ([L] + Kd)** → 쌍곡선. **[L] = Kd일 때 50% 결합** → **Kd가 낮을수록 친화도가 높다**.
- 감: Kd > 10⁻⁵ M 약함, < 10⁻⁸ M 강함. 효소–기질 10⁻⁷~10⁻³ M(생성물을 놓아야 하므로 약함). 항체–항원 10⁻⁸~10⁻¹² M(좋은 항체 ≈ 10⁻¹²).
- **바이오틴–아비딘 ≈ 10⁻¹⁵ M**: 가장 강한 비공유 결합. 아비딘은 **날달걀 흰자**에 많음 → 과다 섭취 시 바이오틴(효소 보조인자) 결핍.
- RNase–RNA도 친화도가 매우 높음 → 각질·먼지의 RNase 때문에 RNA 실험이 어려움.

# B. 마이오글로빈과 헴

## 3. 헴의 구조와 Fe²⁺
**출처** (08 · 24:49 ~ 29:00) ★★★

1. O₂는 물에 잘 안 녹음 → 금속(사람은 **철**, 일부 생물은 구리)을 이용해 운반·저장.
2. **헴(heme)** = **프로토포르피린** 고리 + 가운데 **Fe**. 단백질에 결합한 비단백질 부분 = 보결족(prosthetic group).
3. Fe는 **6배위 결합**: 포르피린 N **4개** + 위아래 2개.
   - 한쪽: 글로빈의 **근위 히스티딘(proximal His)의 이미다졸**.
   - 다른 쪽: **O₂**.
4. Fe는 반드시 **Fe²⁺(페러스)**여야 O₂와 결합. **산화되어 Fe³⁺(페릭)**이면 결합 불가.
5. 헴 구조로 감싸는 이유 중 하나: Fe를 **2가 상태로 유지**.

## 4. 근위·원위 히스티딘
**출처** (08 · 30:20 ~ 32:38) ★★★

마이오글로빈: **153개 아미노산**, α-나선 8개(A~H, N-말단 → C-말단).
| 이름 | 위치 표기 | 서열 번호 | 역할 |
|---|---|---|---|
| **근위 히스티딘(proximal)** | **His F8** (F 나선 8번째) | **His93** | 헴의 Fe에 **직접 배위**(헴과 가까움) |
| **원위 히스티딘(distal)** | **His E7** (E 나선 7번째) | **His64** | Fe에 결합한 **O₂와 수소 결합** |

## 5. CO와 O₂ 선택성
**출처** (08 · 46:29 ~ 49:16), (08 · 01:06:02 ~ 01:07:12) ★★★

1. **자유 헴**: O₂는 Fe에 **비스듬히(굽은 각도)** 결합, **CO는 일직선**으로 예쁘게 결합 → **CO 친화도가 O₂의 20,000배**.
2. **마이오글로빈**: **원위 His E7**이 결합한 **O₂와 수소 결합** → O₂ 선택성 증가 → CO 친화도가 **40배**로 감소.
   〔보충〕 원위 His는 CO가 일직선으로 결합하는 것을 입체적으로도 방해한다(교재).
3. **헤모글로빈**: CO 친화도 ≈ O₂의 **250배**.
4. **일산화탄소 중독**: CO가 결합하면 안 떨어짐 → 빈혈보다 위험. 헤모글로빈의 약 50%가 CO와 결합하면 혼수. 일반인 <1%, **골초 흡연자 최대 15%**(카복시헤모글로빈).

## 6. O₂ 결합 곡선과 산소포화도
**출처** (08 · 32:38 ~ 34:00), (08 · 46:29) ★

- 마이오글로빈: θ = pO₂ / (pO₂ + **P₅₀**) → 쌍곡선(근육 O₂ 저장).
- O₂ 결합 여부에 따라 흡광 파장이 달라짐(동맥혈 선홍색, 정맥혈 검붉음) → **맥박 산소측정기**, 스마트워치 산소포화도의 원리.
- 글로빈 패밀리: 마이오글로빈(근육), 헤모글로빈(적혈구), 뉴로글로빈(뉴런 O₂ 저장), 사이토글로빈(NO 조절).

# C. 헤모글로빈

## 7. 헤모글로빈의 소단위체 계면
**출처** (08 · 49:16 ~ 55:38) ★★★

- 적혈구 무게의 약 34%. 골수 조혈모세포 → 망상적혈구 → 적혈구(핵·미토콘드리아 없음), **수명 120일**, 비장 대식세포가 분해.
- 동맥혈 포화 **96%**, 정맥혈 **64%** → 조직에 약 **1/3(32%)** 내려놓음.
- 마이오글로빈과 **서열 유사성은 낮지만 3차 구조는 매우 비슷** → 기능에 꼭 같은 서열이 필요한 것은 아님.
- **α₂β₂ 이종 사량체**. 소단위체 결합: 소수성 효과 + 수소 결합 + **염다리(이온쌍)**.
  - **α1β1, α2β2**: 30개 이상 잔기 → **강함** (기본 단위 = αβ 이량체).
  - **α1β2, α2β1**: 19개 잔기 → 상대적으로 **약함** → T↔R 전환 시 움직이는 계면.

## 8. T → R 전환의 구조 변화
**출처** (08 · 55:38 ~ 59:02) ★★★

- **T 상태(tense)**: deoxy, O₂ 친화도 낮음. **R 상태(relaxed)**: O₂ 결합, 친화도 높음.
- O₂가 결합하면:
  1. **αβ 이량체끼리의 염다리(빨간색) 수가 줄어듦** → 약해짐.
  2. **His HC3** (H 나선 C-말단에서 3번째 히스티딘)가 T 상태에서는 Lys·Asp 등과 **염다리(이온 다리)**를 이루다가, R 상태에서는 **중앙으로 이동** → 가운데 구멍(공동)이 **좁아짐**.
  3. T 상태의 헴은 **오목(puckered)**, O₂가 결합하면 **평평(flat)**해짐.
  4. 주변 **류신 잔기** 등도 조금씩 틀어짐.
- "크게 안 변하는 것 같지만 실제로는 극적으로 변한다."

〔보충〕 His HC3 = β사슬 C-말단 **His146** (보어 효과의 그 잔기). 헴 평면화 시 Fe가 포르피린 평면 안으로 들어가면서 Fe에 붙은 **근위 His F8과 F 나선을 끌어당김** → α1β2 계면이 재배열된다(교재의 핵심 연결 고리).

## 9. 협동성과 알로스테릭
**출처** (08 · 59:02 ~ 01:06:02) ★★

1. T만 → 친화도 낮은 곡선, R만 → 금방 포화. 실제 Hb는 둘 사이를 오가며 **시그모이드**.
2. **협동성**: O₂가 1개 → 2개 → 3개 결합할수록 남은 자리의 친화도가 **증가(boosting)**.
3. **알로스테릭 단백질**(allo = 다른, steric = 공간): 다른 자리 결합이 기능에 영향. 조절자(modulator)가 원래 리간드면 **동종 영향성(homotropic, O₂)**, 다른 물질이면 **이종 영향성(heterotropic, H⁺·CO₂·BPG)**.
4. **힐 식**: 마이오글로빈 **nH = 1**(비협동), Hb의 순수 R·순수 T도 1. 실제 Hb **nH ≈ 3** (이론상 4).
5. 모델: **MWC(협동, concerted)** — 4개가 한꺼번에 전환 / **순차(sequential)** — 하나씩 전환. 실제는 혼합으로 생각, 아직 명확하지 않음.
6. 마이오글로빈 곡선 ≈ Hb R 상태 → 결합해 계속 쥐고 있음(저장용, 운반엔 부적합: 놓아 주질 않음).

## 10. 보어 효과 (His146)
**출처** (09 · 07:43 ~ 14:39) ★★★

**배경**: 혈중 Hb의 약 40%에 H⁺가 붙어 있고, 10~20%에 CO₂가 직접 붙어 있다. CO₂ + H₂O ⇌ H⁺ + HCO₃⁻ → **CO₂와 H⁺는 같이 움직인다**.

**잔기 메커니즘**
1. **β 소단위체 C-말단의 히스티딘 His146**과, **F 나선–G 나선 사이 루프(FG loop)의 아스파르트산(−)**.
2. pH가 낮으면 His146에 **양성자가 붙어 +** 가 됨.
3. His146(+) – Asp(−) **염다리(이온쌍) 형성**.
4. 이 염다리가 **T 상태를 안정화** → O₂ 친화도 감소 → O₂ 방출.

**생리적 흐름**
- **말초 조직**: pH 낮고 CO₂·H⁺ 많음 → Hb에 H⁺ 결합 → T 상태 → **O₂를 내려놓음**, H⁺를 실음.
- **폐**: O₂ 많음 → O₂ 결합(R 상태) → **H⁺ 방출**.
- 결과: pH가 낮으면 O₂ 결합 곡선이 **오른쪽 이동**. Hb는 O₂ 운반 + **H⁺·CO₂를 말초에서 폐로 운반하는 완충제** 역할.

〔보충〕 이 Asp는 교재 기준 **β Asp94**. 폐에서 방출된 H⁺는 HCO₃⁻와 결합해 CO₂로 바뀌어 날숨으로 나간다.

## 11. CO₂ 카바메이트
**출처** (09 · 14:39 ~ 15:42) ★★★

1. CO₂는 각 폴리펩타이드 **N-말단의 α-아미노기**에 결합.
2. → **카바미노(카바메이트, –NH–COO⁻)** 형성 (이때 H⁺도 생김).
3. 카바메이트는 **음전하** → 염다리 형성을 도와 **T 상태 유지** → O₂ 방출 촉진.
4. 폐에서 CO₂를 내려놓고 O₂를 받아 말초로 → 말초에서 다시 CO₂를 실음.

## 12. 2,3-BPG
**출처** (09 · 15:42 ~ 24:30) ★★★

**분자**: **2,3-비스포스포글리세레이트(BPG)** — 해당 과정의 곁가지 산물. 글리세롤 골격 C3, **2·3번 탄소에 인산기 2개 + 카복실기** → **음전하가 매우 큼**.

**결합 메커니즘**
1. Hb 중앙, **두 β 소단위체 사이의 공동(cavity)**에 결합.
2. 공동 내부에 **양전하 아미노산**이 많음 → BPG의 음전하와 정전기적 결합.
3. **Hb 1분자당 BPG 1분자**.
4. **T 상태(deoxy)에만 결합**. O₂가 결합해 R 상태가 되면 구조가 뒤틀려 **공동이 좁아져** BPG가 들어갈 수 없음.
5. → **BPG는 T 상태를 유도·안정화** → O₂ 친화도 감소.

**수치·생리**
- BPG = 0 → Hb 곡선이 **쌍곡선(R 상태 같음)** → 운반에 부적합.
- 해수면 정상 BPG ≈ **5 mM** → 시그모이드. 폐 pO₂ ≈ **13 kPa**(포화 ≈ 1) → 조직 ≈ **4 kPa** → **38%** 방출.
- **고산지대(약 4,500 m)**: 폐 pO₂ ≈ **7 kPa** → 같은 곡선이면 방출 **30%**로 감소(8% 손실).
- **적응**: BPG를 **5 → 8 mM**로 증가 → 곡선 **오른쪽 이동** → 방출 **37%**로 회복.
- BPG는 바로 늘지 않으므로 고산 적응에 시간이 걸림 → 고지대 경기 전에 미리 가는 이유.

〔보충〕 공동의 양전하 잔기 = 각 β사슬의 **Val1(N-말단 아미노기), His2, Lys82, His143**.

## 13. 태아 헤모글로빈 HbF
**출처** (09 · 24:30 ~ 28:49) ★★★

- 성인 **HbA = α₂β₂**(90% 이상), **HbA2 = α₂δ₂**, 태아 **HbF = α₂γ₂**. 출생 후 약 6개월에 걸쳐 γ → β로 교체.
- **메커니즘**: β의 BPG 결합 부위 **히스티딘(+)**이 γ에서는 **세린(중성)** → BPG 결합 부위 양전하 감소 → **BPG 친화도 감소** → T 상태 안정화가 덜 됨 → **O₂ 친화도 증가**.
- 의미: 태아는 직접 호흡하지 않으므로 **엄마 HbA에서 O₂를 빼앗아야** → HbA보다 O₂ 친화도가 높아야 함. 출생 후엔 시그모이드로 조직 공급이 효율적인 HbA로 전환.

〔보충〕 해당 잔기 = **β His143 → γ Ser143**.

## 14. HbA1c
**출처** (09 · 28:49 ~ 30:31) ★★

1. HbA의 **β사슬 N-말단 α-아미노기에 글루코스가 비효소적으로** 붙음(당화, glycation).
2. 혈당이 높을수록 많이 생김.
3. 적혈구 수명 120일 → **최근 2~3개월 평균 혈당** 반영.
4. **6.5% 이상**이면 당뇨 가능성 높음.

〔보충〕 β N-말단 잔기는 **Val**. 글루코스 알데하이드와 아미노기가 시프 염기 → 아마도리 재배열로 안정 결합.

# D. 헤모글로빈병증

## 15. 겸상 적혈구 빈혈증 HbS
**출처** (09 · 30:31 ~ 36:03) ★★★

1. **β 소단위체 유전자 GAG → GTG** → **글루탐산 → 발린**.
2. 음전하(친수성) 잔기가 **소수성** 잔기로 바뀜.
3. 발린끼리 **소수성 효과**로 Hb 분자들이 달라붙어 **섬유(fiber)** 형성(아밀로이드화와 같은 맥락).
4. 적혈구 안에 섬유 → **낫(sickle) 모양**, 원반형의 유연성 상실.
5. → 좁은 모세혈관 통과 못함, 터짐 → 수명 120일 → **약 20일** → **빈혈** + 혈관 폐색 → 통증(뇌에서 편두통 등).
6. 질환이 분자·유전적으로 일어남이 밝혀진 **최초 사례**.

**말라리아 저항성**: 말라리아 원충은 적혈구에서 증식. 낫 모양·산소 부족 환경에서는 잘 번성 못함 → **이형접합(heterozygote)**은 평소엔 정상 Hb로 살면서 **말라리아 저항성** → 자연 선택으로 유지 → 말라리아 유행 지역과 분포가 겹침.

〔보충〕 위치는 **β6** (Glu6Val). 발린이 다른 Hb의 Phe85·Leu88 소수성 패치에 끼어들고, 이 패치는 **deoxy(T) 상태에서만 노출** → 산소가 적을 때 겸상화가 심해진다.

## 16. HbC와 전기영동
**출처** (09 · 36:03 ~ 38:18) ★★

- **HbC**: 같은 자리 **Glu(−) → Lys(+)**.
- 전기영동(− 쪽에 로딩, + 쪽으로 이동): HbA(Glu, 음전하 많음) **가장 빠름** > HbS(Val) > HbC(Lys) **가장 느림** → 유전자 검사 없이 감별.

## 17. 탈라세미아
**출처** (09 · 38:18 ~ 42:47) ★★

- HbS/HbC = 단백질은 만들어지나 기능 이상 / **탈라세미아 = Hb 소단위체 발현 자체가 부족**.
- **α-탈라세미아**: α 유전자는 **16번 염색체에 2개 × 부모 = 4개**.
  - 1개 결손: 무증상 보인자(silent carrier).
  - 2개 결손: 경미한 증상(발현 약 절반).
  - 3개 결손: **HbH = β₄** → 쉽게 **침전**, 심한 빈혈.
  - 4개 결손: 태아 사망 또는 **태아수종(hydrops fetalis)**, **Hb Bart's = γ₄**.
  - 유전자 4개라 보상이 가능해 상대적으로 드묾.
- **β-탈라세미아**: β는 부모에게서 1개씩(2개). 한쪽 → minor, 양쪽 → **major**: HbF·HbA2로 버티고, 심하면 **α만 남아 침전** → O₂ 운반 실패.
- 이형접합은 말라리아 저항성 → 지중해 지역에 많음 → **지중해성 빈혈**.

## 18. 메트헤모글로빈
**출처** (09 · 42:47 ~ 44:27) ★★

1. 헴 철이 **Fe³⁺(페릭)**로 산화된 Hb = **메트헤모글로빈(HbM)** → O₂ 결합 불가.
2. 증상: **청색증(cyanosis)**, 초콜릿색 혈액.
3. 원인: **ROS를 유발하는 약물** 등에 의한 산화.
4. 정상적으로는 **NADH-사이토크롬 b5 환원효소**가 전자를 넣어 Fe³⁺ → Fe²⁺로 되돌림. 이 효소의 **유전적 결함** 시 발병.

# E. 면역 단백질

## 19. 항체 구조
**출처** (09 · 44:27 ~ 49:58) ★★

- 체액성 면역 = **B세포가 만든 항체**, 세포성 면역 = 세포독성 T·헬퍼 T(지휘), 기억 세포.
- **항원**: 항체가 인식하는 물질 / **에피토프**: 항원 중 항체가 **직접** 인식하는 부위(단백질이면 아미노산 약 8~10개).
- **합텐(hapten)**: 너무 작아 혼자서는 면역 반응을 못 일으키지만 **단백질에 붙으면** 항체가 인식 → 예: **페니실린** 알레르기.
- **IgG**: Y자. **파파인**(펩티데이스)으로 자르면 3조각 → **Fab** 2개(fragment antigen binding, **가변 부위**에 에피토프 결합, 팔 2개) + **Fc** 1개(fragment crystallizable, 결정화되는 부분). IgA, IgD, IgE, IgM도 있음.

## 20. Fc 수용체와 ADCC
**출처** (09 · 49:58 ~ 53:16) ★★

**식작용 경로**
1. 항체 Fab가 바이러스 등을 잡음.
2. **대식세포**가 **Fc 수용체**로 항체의 Fc를 인식 → 통째로 삼킴(**식작용**) → 분해.
3. 조각을 **제시(presentation)** → 그 항원에 대한 항체·TCR 생산 유도(적응 면역).

**ADCC — 트라스투주맙(허셉틴)**
1. 유방암·난소암 세포에 **HER2**(성장인자 수용체) 과발현 → 암 성장.
2. **트라스투주맙** = HER2에 대한 (모노클로날) 항체 → HER2에 결합.
3. 결합한 항체의 **Fc**를 면역 세포가 인식.
4. **이펙터 세포(T세포, NK세포)**가 **퍼포린** 등을 분비 → 세포에 구멍 → **종양 세포 제거**.
5. = **항체 의존성 세포 매개 세포독성(ADCC)**.

## 21. 항체의 유도 적합과 클론
**출처** (09 · 53:16 ~ 56:14) ★

- 항원이 결합하면 항체 결합 부위의 모양이 조금 바뀌어 더 잘 감쌈 = **유도 적합**.
- 한 항원의 여러 에피토프에 대해 여러 B세포 클론이 만든 항체 = **폴리클로날** / 가장 좋은 한 클론만 = **모노클로날**(허셉틴).

# F. 근육 단백질

## 22. Ca²⁺와 트로포닌·트로포마이오신
**출처** (09 · 01:02:03 ~ 01:06:07) ★★★

**구성**
- **얇은 필라멘트**: **α-액틴**(근육용, 고정된 틀; 비근육은 β-액틴). G-액틴(구형) → **ATP를 써서** F-액틴(필라멘트).
- **굵은 필라멘트**: 마이오신.

**수축 개시 메커니즘**
1. 평소: **트로포마이오신**이 액틴을 감아 **마이오신 결합 부위를 가림(masking)** → 마이오신이 액틴에 못 붙음.
2. 신경 신호가 근육에 도달.
3. **근소포체(sarcoplasmic reticulum, 근육의 ER)**에서 **Ca²⁺ 방출** → 세포 내 Ca²⁺ 급증.
4. Ca²⁺가 **트로포닌 복합체(I, C, T) 중 트로포닌 C**에 결합.
5. 트로포닌 C가 **트로포마이오신의 구조(위치)를 바꿈** → 마이오신 결합 부위 노출.
6. 마이오신 헤드가 액틴에 결합 가능.

**구조 계층**: 근육 → 근섬유(= 근육 세포) → 수천 개 근원섬유 → 기본 단위 **근절(sarcomere)**. 마이오신은 "콩나물" 두 개가 꼬인 꼬리 + 숙인 **헤드**(액틴 결합 부위). 여러 개가 숙주나물처럼 뭉쳐 굵은 필라멘트.

## 23. 액토마이오신 사이클과 사후 경직
**출처** (09 · 01:07:06 ~ 01:09:58) ★★★

1. **결합 상태**: 마이오신 헤드가 액틴에 붙어 있음.
2. **ATP 결합** → 마이오신 헤드가 액틴에서 **떨어짐(detach)**.
3. **ATP 가수분해(ADP + Pi는 헤드에 남음)** → 구조 변화로 헤드가 **앞으로 젖혀짐**(재장전).
4. **Pi 방출** → 헤드가 액틴에 **다시 결합**.
5. **ADP 방출**과 함께 **파워 스트로크** → 액틴 필라멘트를 끌어당김 → **수축**.
6. 다시 ATP가 오면 2번부터 반복: 떨어짐 → 스트로크 → 떨어짐 → 스트로크.

**사후 경직(rigor mortis)**: ATP가 없으면 2번(떨어지기)이 불가 → 액틴–마이오신이 **결합 상태로 고정** → 몸이 굳음. **ATP는 수축이 아니라 "떨어지는 데" 필요**하다는 점이 핵심.
