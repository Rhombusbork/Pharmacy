# A. 결합과 다당류

## 1. 글라이코사이드 결합과 환원당
**출처** (12 · 글라이코사이드 결합의 형성, 꼭 알아야 할 이당류) ★★

1. 한 당의 **아노머 탄소(C1)의 OH** + 다른 당의 OH → **물이 빠지며** O를 사이에 둔 공유 결합 = **O-글라이코사이드 결합**.
2. 결합에 쓰인 쪽: **헤미아세탈 → 아세탈**. 아세탈은 고리가 잘 안 풀림 → 선형(알데하이드)으로 못 돌아감 → **환원력 상실**.
3. 결합에 안 쓰인 쪽 아노머 탄소가 OH로 남으면 → 헤미아세탈 유지 → **환원당**.
4. **단방향 화살표(1→4)** = 한쪽 아노머만 사용 → 환원당. **양방향 화살표(1↔2, 1↔1)** = 양쪽 아노머 모두 사용 → **비환원당**.

| 이당류 | 표기 | 환원성 |
|---|---|---|
| 말토스(엿당) | Glc(α1→4)Glc | 환원당 |
| 락토스(젖당) | Gal(β1→4)Glc | 환원당 |
| 수크로스(설탕) | Glc(α1↔2β)Fru | **비환원당** |
| 트레할로스 | Glc(α1↔1α)Glc | **비환원당** (버섯·효모·곤충의 스트레스 보호제) |

## 2. α1→4 vs β1→4
**출처** (12 · 셀룰로스, α1→4와 β1→4 결합의 구조적 차이) ★★

- **α1→4**(녹말·글라이코젠): C1의 OH가 아래 → 결합이 **꺾임** → **나선**(아밀로스). 효소가 접근하기 쉬움.
- **β1→4**(셀룰로스): OH가 위 → 단위가 위아래 번갈아 → **곧게 펴진 사슬**, OH가 위아래로 있어 사슬끼리 **수소 결합으로 안정한 층** → 촘촘하게 패킹 → 효소 활성 부위가 접근하기 어려움 → 소화 어려움.
- 녹말 = **아밀로스**(α1→4 선형) + **아밀로펙틴**(α1→4 + **α1→6 가지**, 24~30개마다). **글라이코젠**은 가지가 **8~12개마다**로 더 촘촘.
- 다당류는 DNA·단백질과 달리 **주형이 없다** → 효소의 고유 특성이 구조를 결정.

## 3. 글라이코젠으로 저장하는 이유
**출처** (12 · 왜 포도당을 글라이코젠으로 저장하는가, 왜 가지가 많은가) ★★

1. 간세포에 포도당 그대로 저장 → 약 **0.4 M** → **삼투압**으로 물이 대량 유입 → 삼투 스트레스·파열.
2. 공유 결합으로 묶어 글라이코젠으로 → 약 **0.01 μM** (약 10⁷배 감소) → 삼투 부담 해소.
3. **가지가 많은 이유**: 포도당은 사슬 끝에서 하나씩 떼므로, 끝(가지)이 많을수록 **여러 곳에서 동시에 빠르게** 동원.

## 4. 셀룰로스와 셀룰레이스
**출처** (12 · 셀룰로스와 소화) ★★

- 사람은 β1→4를 못 끊음 → **식이섬유**로 그대로 배출.
- 소(반추위)·흰개미도 **직접** 못 끊음 → 공생 **미생물이 셀룰레이스**를 분비해 분해.
- 그래서 항생제를 잘못 쓰면 미생물이 죽어 소가 먹어도 에너지를 못 얻음.

## 5. 키틴
**출처** (12 · 키틴) ★

- **N-아세틸글루코사민(GlcNAc)**의 **β1→4** 선형 동종다당류(곤충).
- N-아세틸기가 극성을 줄여 더 **소수성** → 잘 분해되지 않는 저항성.

## 6. 펩티도글라이칸, 페니실린, 라이소자임
**출처** (12 · 펩티도글라이칸) ★★★

1. 구조: **GlcNAc**와 **N-아세틸뮤람산(MurNAc)**의 이당류가 β1→4로 반복된 사슬 + **사슬 사이를 펩타이드로 교차 결합**.
2. 그람 양성: 두껍게 바깥 / 그람 음성: 두 막 사이에 얇게. 사람에는 없음 → 항생제 표적.
3. **페니실린**: 교차 결합 효소 **트랜스펩티데이스**를 억제 → 세포벽 연결 실패. (활성 부위 Ser와 공유 결합 — Ch6 문서 15번)
4. **라이소자임**(눈물·침의 항균 단백질): **MurNAc와 GlcNAc 사이 β1→4 결합을 절단** → 세균이 터짐.

〔보충〕 라이소자임 활성 부위의 **Glu35(일반 산)·Asp52(친핵체)**가 글라이코사이드 결합을 자른다(교재 Ch6 효소 예).

# B. 소화와 흡수

## 7. 소화 효소 순서
**출처** (12 · 탄수화물의 소화와 흡수) ★★

1. **입**: 침 **α-아밀레이스**가 녹말 절단.
2. **위**: 산에 의해 아밀레이스 **불활성화**.
3. **소장**: 이자 **α-아밀레이스** → 말토트라이오스, 말토스 등.
4. **소장 상피세포 막 효소**: **아이소말테이스(α1→6), 말테이스, 락테이스, 수크레이스** → 단당류.
- α-아밀레이스는 **α1→4만** 자름. **β1→4(셀룰로스)는 못 자름**.

## 8. 단당류 흡수
**출처** (12 · 단당류의 흡수) ★★★

1. **Na⁺/K⁺ ATPase**(기저측막)가 ATP로 Na⁺를 퍼내 장세포 안 Na⁺를 낮게 유지 → **Na⁺ 농도 기울기**.
2. **포도당·갈락토스**: 관강 쪽 **SGLT1**이 **Na⁺와 함께** 기울기를 타고 세포 안으로(공동수송).
3. 세포 안 포도당·갈락토스 → **GLUT2**를 통해 혈액으로.
4. **과당**: **GLUT5**로 들어감 → **Na⁺ 기울기 불필요**(촉진 확산).

〔보충〕 과당도 혈액으로 나갈 때는 GLUT2를 쓴다.

## 9. 젖당 불내증
**출처** (12 · 젖당 불내증) ★★

1. 아기 때 **락테이스** 발현 → 락토스 분해. 성인이 되면(아시아·아프리카인 90% 이상) 발현 감소.
2. 원인: **2번 염색체 락테이스 유전자의 SNP** — 아시아인은 나이 들면 발현이 꺼지는 변이, 유제품을 많이 먹어 온 인종은 성인에서도 발현되는 변이.
3. 분해 안 된 락토스 → **대장**으로 → 대장 세균이 **발효** → **아세트산 등 유기산, CO₂, 메테인, H₂**.
4. **날숨의 H₂**를 측정해 **진단**.
5. 락토스가 **물을 끌고 가** → **설사**, 심하면 탈수.
6. 대처: 요거트·치즈(락토스가 이미 분해된 발효 제품), 칼슘은 브로콜리 등으로 보충.

# C. 세포외기질과 당접합체

## 10. GAG의 쿠션 메커니즘
**출처** (12 · 왜 쿠션 역할을 하는가) ★★

1. GAG = **산성당**(D-글루쿠론산 또는 L-이두론산) + **아미노당**(GlcNAc 또는 GalNAc) 이당류의 반복.
2. **카복실기·황산기** → **음전하가 매우 많음**.
3. 음전하가 **Na⁺**를 끌어오고, Na⁺는 **물과 함께** 옴.
4. → 물을 많이 품어 **쿠션(충격 흡수)**, 관절에서 **윤활**.
- ECM 구성: GAG(이종다당류) + 섬유 단백질(콜라겐=밧줄·철근, 엘라스틴, **피브로넥틴**=연결). **인테그린** = 막 단백질, 안팎 양방향 신호.

## 11. 주요 GAG
**출처** (12 · 주요 GAG의 종류) ★

- **히알루론산(히알루로난)**: **단백질에 공유 결합하지 않음**, **황산기 없음**. 관절 활액 충격 흡수.
- **콘드로이틴 황산**: 연골에 가장 많음, 인장 강도.
- **케라탄 황산**: **우론산 없음**.
- **더마탄 황산**: 피부.
- **헤파린**: 비만세포 안/분비(가용성). **헤파란 황산**: 세포 ECM·세포 표면.

## 12. 헤파린과 혈액 응고
**출처** (12 · 헤파린과 혈액 응고) ★★★

1. **비만세포**가 알레르기·염증 시 히스타민과 함께 **헤파린** 분비.
2. 응고의 핵심 단백질 **트롬빈**을 억제하는 것은 **안티트롬빈**.
3. 헤파린은 **황산기(−)**가 많아 안티트롬빈의 **양전하 부위(파란색)**에 잘 결합.
4. → **트롬빈–안티트롬빈 복합체** 형성을 도움 → 트롬빈 억제 → **응고 억제**.
5. 의미: 염증·알레르기 부위에서 응고가 일어나면 더 위험하므로 비만세포가 막는다. 상처 연고에도 사용.

## 13. 헤파란 황산의 4가지 기능
**출처** (12 · 헤파란 황산의 기능) ★★★

헤파란 황산 도메인: **NS(황산기 많음)** / **NA(GlcNAc 많음)**.
1. **안티트롬빈 활성화(형태 변화)**: NS 도메인이 안티트롬빈에 결합 → **안티트롬빈의 구조 변화** → 응고 인자 **Xa, IXa, XIa**에 대한 친화도 증가 → 응고 억제.
2. **트롬빈–안티트롬빈 플랫폼**: NS 도메인에 안티트롬빈(구조 변화), 다른 부위에 **트롬빈**이 붙어 둘을 가까이 모음 → 항응고.
3. **성장인자 공동수용체**: 음전하에 **FGF**가 붙음 → 근처 **FGF 수용체**에 전달 → 적은 리간드로도 신호.
4. **지질단백질 분해효소(lipoprotein lipase) 고정**: 희석되지 않게 근육세포·지방세포 막 근처에 붙잡아 둠 → 지질 분해 → 지방산이 세포로 흡수.

## 14. 프로테오글라이칸
**출처** (12 · 프로테오글라이칸, 막 프로테오글라이칸) ★★

1. **핵심 단백질(core protein)**의 **Ser–Gly 서열에서 Ser의 –OH**에 연결 부위(linker) 당이 순서대로 붙고, 그 위에 GAG가 붙음. 예: 관절의 **어그리칸**.
2. **히알루론산은 단백질과 공유 결합하지 않음** → **연결 단백질(link protein)**과 이온 상호작용 등으로 결합 → 히알루론산을 중심축으로 프로테오글라이칸이 붙은 거대 **집합체**.
3. 막 헤파란 황산 프로테오글라이칸:
   - **신데칸**: 막 **관통** 단백질 → 세포 내부와 직접 연결, 부착·이동·신호전달.
   - **글리피칸**: **GPI 앵커(글라이코실포스파티딜이노시톨)**로 막 지질에 고정 → 성장인자·효소와 결합해 성장·분화 조절.

## 15. 당단백질
**출처** (12 · 당단백질) ★★

| | O-연결 | N-연결 |
|---|---|---|
| 붙는 곳 | **Ser·Thr의 –OH** | **Asn 아마이드기의 N** |
| 방식 | **골지체**에서 하나씩 | **ER**에서 시작, 당 덩어리를 **한꺼번에** |

- 분포: 점막 **뮤신**(미끈미끈), 대부분의 **분비 단백질**, 혈액 단백질.
- 기능: 당이 떨어지면 **안정성↓·빨리 분해**. 항체·호르몬은 **글라이코실화**가 적절해야 반감기·기능 유지. 접힘·안정성, **표적화(어디로 갈지)**, 인식에 관여. 학문 = 당체학(glycomics).

## 16. 당지질과 LPS
**출처** (12 · 당지질, ABO 혈액형, 지질다당류) ★★

- **스핑고당지질**: 신경세포에 많음, 신호전달.
- **강글리오사이드**: **시알산(= N-아세틸뉴라민산, Neu5Ac)**이 1개 이상 붙은 스핑고당지질 → **콜레라 독소 수용체** 등.
- **ABO 혈액형**: 적혈구 막 스핑고지질에 붙은 **당 구조**가 A·B·O·AB 결정.

# D. 당 코드와 렉틴

> **당 코드**: 주형은 없지만 어떤 당이 어떻게 연결되느냐로 거의 무한한 정보. **렉틴** = 당 코드를 읽는 단백질(특히 시알산 결합). 결합 원리: **수소 결합 + 소수성 상호작용**.

## 17. 인플루엔자와 타미플루
**출처** (12 · 인플루엔자 바이러스와 타미플루, 타미플루 내성) ★★★

**바이러스 표면 단백질** — 종류에 따라 H1N1, H5N1 등.
1. **침입**: **HA(헤마글루티닌) = 바이러스의 렉틴** → 우리 세포의 **시알산이 붙은 수용체**를 인식해 결합 → 세포 안으로.
2. **복제**: 세포 기구를 이용.
3. **방출**: 새 바이러스가 나가려면 HA–시알산 결합을 끊어야 함 → **NA(뉴라미니데이스) = 시알리데이스** 활성으로 시알산 절단 → 분리.

**오셀타미비르(타미플루)**
- 구조가 **시알산(N-아세틸뉴라민산)과 비슷** → NA 활성 부위에 대신 들어감 → 시알산 절단 불가 → 바이러스가 세포에서 떨어지지 못함 = **경쟁적 저해제**.
- **고열 후 48시간 이내** 복용해야 효과: 복제된 바이러스가 나가려는 시점에 막아야 하므로, 이미 다 퍼진 뒤에는 의미 없음.
- **자나미비르(리렌자)**: 같은 원리, **흡입제** → 호흡기 질환자 사용 주의.

**내성 돌연변이 H274Y**
1. NA의 **274번 히스티딘 → 타이로신**.
2. → **276번 글루탐산**의 위치가 약간 어긋남.
3. → 오셀타미비르는 제대로 못 끼어 들어가지만, 원래 기질 **시알산은 여전히 잘 들어감** → 내성.

〔보충〕 H274Y는 N2 번호 체계 기준이며, N1(H1N1)에서는 H275Y로 부르기도 한다. Glu276이 회전해야 오셀타미비르의 소수성 펜틸에터 곁사슬이 들어갈 주머니가 생기는데, Tyr의 큰 곁사슬이 이 회전을 막는다.

## 18. 셀렉틴과 백혈구 침윤
**출처** (12 · 백혈구의 침윤과 셀렉틴) ★★★

1. 감염·염증 부위 세포가 **사이토카인·케모카인** 분비.
2. 근처 **혈관 내피세포**가 **P-셀렉틴**(렉틴의 일종) 발현.
3. **포착**: 혈류 속 백혈구의 **시알릴 루이스 X**를 가진 당단백질이 P-셀렉틴에 **약하게** 결합.
4. **구르기(rolling)**: 빠르게 돌던 백혈구가 감속해 굴러감.
5. **단단한 부착**: **인테그린**과 결합해 완전히 멈춤.
6. **이동(transmigration)**: 케모카인 신호로 모양을 바꿔 내피세포 사이를 비집고 조직으로.

## 19. 헬리코박터 파일로리
**출처** (12 · 헬리코박터 파일로리) ★★

1. 균의 렉틴 **BabA, SabA**가 위 점막 당 항원(**루이스 b 항원**, **시알릴 루이스 X**)을 인식해 부착·감염.
2. 루이스 b는 **O형 항원과 구조가 비슷** → **O형의 감염률이 가장 높다**.

〔보충〕 BabA는 루이스 b(혈액형 항원), SabA는 시알릴 루이스 X(염증 시 증가)와 결합한다.

## 20. 만노스-6-인산과 리소좀 표적화
**출처** (12 · 단백질 표적화, I-세포병, 히스티딘의 역할) ★★★

**표적화 경로**
1. **ER**: 단백질 합성 중 **Asn에 N-연결 당** 부착.
2. **시스-골지**: 당 사슬 **만노스의 6번 위치 인산화** → **만노스-6-인산(M6P)**.
3. **트랜스-골지**: **M6P 수용체**가 인식해 결합.
4. 수용체가 단백질을 **리소좀**으로 운반.
→ "M6P를 가진 단백질은 리소좀으로 간다."

**수용체의 pH 스위치 (His)**
1. M6P는 **음전하**. 수용체와 결합하려면 적절한 **염다리** 필요(트랜스-골지, 중성에 가까운 pH).
2. 리소좀(엔도솜)에 오면 **pH 4~5**로 낮아짐.
3. 수용체의 **히스티딘이 양성자화** → 결합(염다리)을 방해 → **단백질 방출**.
4. 빈 수용체는 **재활용**되어 골지로 돌아가 다음 단백질을 운반.
→ Ch2 문서 1번(His pKa 6.0 스위치)의 또 다른 예.

**I-세포병(inclusion cell disease)**
1. 만노스에 인산을 붙이는 효소의 **돌연변이** → M6P가 안 생김.
2. 리소좀 효소가 리소좀으로 못 가고 **기본 경로(분비)**로 → 혈액 등에 리소좀 효소가 많아짐.
3. 리소좀 안에서는 분해가 안 되어 물질이 쌓임(봉입체) → **골격 이상, 관절 운동 제한** 등 → 조기 사망.

〔보충〕 인산을 붙이는 효소 = **GlcNAc 포스포트랜스퍼레이스**(GlcNAc-1-인산을 만노스 6번에 붙인 뒤 GlcNAc를 떼어 M6P 노출).
