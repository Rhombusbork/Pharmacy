## 1. 11-시스-레티날 → 올-트랜스-레티날
**출처** (02 · 14:27 ~ 15:44) ★★

**등장 분자**: 레티날(retinal, 비타민 A 유래), 11번 탄소의 C=C 이중 결합

**메커니즘**
1. 레티날은 비타민 A로부터 만들어지며, 망막 세포에 **11-시스-레티날(11-cis-retinal)** 형태로 있다. 11번 탄소의 이중 결합을 기준으로 양쪽 치환기가 **같은 방향(시스)**.
2. C=C 이중 결합은 회전할 수 없으므로 시스·트랜스는 서로 다른 분자로 "고정"된다.
3. **빛 에너지**가 들어오면 이 이중 결합이 바뀌어 **올-트랜스-레티날(all-trans-retinal)**, 즉 반대 방향(트랜스)이 된다.
4. 분자 모양이 완전히 바뀌는(transformation) 이 이성질화가 **빛 감지 → 시각**의 출발점이다.

**왜 중요한가**
- 시스-트랜스(기하) 이성질체의 대표 예. "이중 결합이라 회전 불가 → 시스/트랜스가 고정 → 세포는 두 형태를 완전히 다른 물질로 인식"이라는 논리.
- 같은 예로 말레산(시스, COOH 같은 쪽) / 푸마르산(트랜스).

〔보충〕 레티날은 옵신 단백질의 Lys 잔기와 시프 염기(Schiff base)로 결합해 로돕신을 이루고, 광이성질화로 옵신의 형태가 바뀌어 G 단백질(트랜스듀신) 신호가 시작된다. 강의에서는 "나중에 또 기회가 있을 때"라고 넘어갔음.

## 2. 아스파탐: 입체 특이적 수용체 인식
**출처** (02 · 24:20 ~ 25:46) ★★

**등장 분자**: 아스파탐 = **L-아스파르트산 + L-페닐알라닌**이 연결된 다이펩타이드(유도체), 미각 세포의 단맛 수용체

**메커니즘**
1. 아스파탐(L-Asp–L-Phe)이 미각 세포의 **수용체(receptor)**에 결합 → 수용체를 자극해 신호 → **단맛**.
2. 페닐알라닌을 **D형**으로 바꾼 분자(L-Asp–D-Phe)도 수용체에 **결합은 똑같이** 한다.
3. 그러나 **수용체의 형태(conformation) 변화를 다르게** 일으켜서 **쓴맛**으로 느껴진다.

**핵심 논리**: 결합 여부가 아니라 "결합 후 수용체 형태를 어떻게 바꾸느냐"가 신호를 결정 → 생체는 **입체 특이적(stereospecific)**.

## 3. 시탈로프람: S형만 약효
**출처** (02 · 25:46) ★★

**등장 분자**: 시탈로프람(citalopram, 우울증 약, **세로토닌 재흡수 억제제**)

**메커니즘**
1. 합성하면 **S형과 R형**이 동시에 만들어진다(라세미).
2. 쐐기(진한 선)=앞으로 튀어나옴, 점선=뒤로 들어감 → 어느 치환기가 앞으로 나오느냐가 다르다.
3. 약물과 결합하는 표적 단백질은 **S형에만 결합**하고 R형은 결합하지 않는다 → **S형이 활성형(active form)**.
4. 이유: **단백질의 형태가 입체 특이적**이기 때문.

〔보충〕 S형만 분리한 약이 에스시탈로프람(escitalopram). 표적은 세로토닌 수송체(SERT).

- 참고: 생체 분자(당·아미노산)는 **D/L**, 복잡한 약물은 **R/S**(CIP 규칙, 시계 방향=R rectus, 반시계=S sinister)로 표기. (02 · 21:11 ~ 22:21)

## 4. 짝지음 반응: 글루코스 → 글루코스 6-인산
**출처** (02 · 37:03 ~ 38:19) ★★

**등장 분자**: 글루코스, ATP, 글루코스 6-인산(G6P) / 〔보충〕 효소 = 헥소카이네이스(Ch6 강의에서 EC 2.7.1.1로 다시 등장)

**메커니즘**
1. 해당 과정의 첫 단계: 글루코스 6번 탄소에 인산기를 붙여 G6P를 만들어야 함.
2. 이 반응 자체는 **ΔG > 0** (흡에너지, endergonic) → 혼자서는 일어나지 않는다.
3. **ATP 가수분해**는 큰 **음(−)의 ΔG** (발에너지, exergonic).
4. 두 반응을 **결합(짝지음, coupling)** → 전체 ΔG가 음수가 되어 G6P가 **자발적으로** 만들어진다.

〔보충〕 수치: 글루코스 + Pi → G6P ΔG′° ≈ +13.8 kJ/mol, ATP → ADP + Pi ΔG′° ≈ −30.5 kJ/mol, 합 ≈ −16.7 kJ/mol.

**관련 식** (02 · 31:57 ~ 46:45)
- ΔG = ΔH − TΔS (ΔG < 0 이면 자발적)
- ΔG′° = −RT ln K′eq → K′eq > 1 ⇔ ΔG′° < 0 ⇔ 정반응 자발적

## 5. 해당 과정 Keq vs Q
**출처** (02 · 41:49 ~ 43:03) ★★

**등장 효소**: 헥소카이네이스(hexokinase), **PFK-1**, **피루브산 카이네이스(pyruvate kinase)** / 알돌레이스(aldolase), 트라이오스인산 아이소머레이스(triose phosphate isomerase)

**메커니즘(개념)**
1. 각 효소 반응의 **평형 상수 K′eq**는 고정된 값.
2. 실제 세포(간, 심장)의 기질·생성물 농도로 계산한 **질량 작용비 Q**는 조직·상황마다 다르다.
3. **알돌레이스, TPI**: K′eq와 Q의 차이가 100배 이내 → 거의 평형 → "그냥 통과하는" 단계.
4. **헥소카이네이스, PFK-1, 피루브산 카이네이스**: K′eq와 Q가 100배 이상 차이 → 평형과 멀리 떨어져 있음 → **반응(속도)을 결정하는 조절 단계**.

〔보충〕 평형에서 멀다 = ΔG가 크게 음수 = 사실상 비가역 → 세포는 이 단계의 효소를 조절해 흐름을 통제한다(2학기 대사에서 자세히).

## 6. 효소와 활성화 에너지
**출처** (02 · 44:37 ~ 48:36) ★★

**메커니즘**
1. A → B의 ΔG(바닥 상태끼리의 차이)는 **효소가 있든 없든 같다**.
2. 사이에 **활성화 에너지(‡, 대거 표시)**라는 언덕이 있어서, 자발적이어도 느리다.
3. 효소는 이 **언덕을 낮춰** 반응 속도를 엄청나게 빠르게 한다. **평형 상수는 바꾸지 않는다.**
→ Ch6에서 "결합 에너지로 전이 상태를 안정화"로 이어짐.

## 7. 되먹임 억제: 트레오닌 → 아이소류신
**출처** (02 · 48:36 ~ 50:00) ★★

**등장 분자**: 트레오닌(Thr), 아이소류신(Ile), 경로의 첫 효소

**메커니즘**
1. 트레오닌이 여러 단계를 거쳐 아이소류신이 된다.
2. 아이소류신이 너무 많아지면 → **최종 생성물인 아이소류신이 첫 번째 단계(속도 조절 단계, rate-limiting step) 효소를 억제**.
3. 필요 없는 생산을 멈춰 자원·에너지 낭비를 막는다 = **되먹임 억제(feedback inhibition)**.

〔보충〕 첫 효소는 **트레오닌 탈수화효소(threonine dehydratase)**이고, 아이소류신은 활성 부위가 아닌 다른 자리(알로스테릭 부위)에 결합한다 → Ch5·Ch6의 "알로스테릭 조절"과 연결.

## 8. 유전자 중복과 파라로그
**출처** (02 · 01:01:34 ~ 01:05:51), (06 앞부분 복습) ★

**메커니즘**
1. 헥소카이네이스 유전자가 DNA 복제 중 **중복(duplication)**된다.
2. 원래 사본은 글루코스 대사에 필수 → 돌연변이가 생기면 생존 불가 → 보존된다.
3. 복사본은 원본이 있으니 돌연변이가 쌓여도 괜찮다 → 우연히 **갈락토스를 쓰는 헥소카이네이스 같은 효소**가 생김 → 두 당을 다 쓰는 개체가 **선택**된다.
4. 같은 종 안에서 이렇게 생긴 상동 유전자 = **파라로그(paralog)**. 다른 종(사람·쥐·효모)의 같은 헥소카이네이스끼리 = **오솔로그(ortholog)**. 둘 다 **상동 유전자(homolog)**.

- 콜라겐 23개 유전자도 파라로그 관계(Ch4 콜라겐병증에서 다시 나옴).

## 9. 아세틸-CoA의 작용기
**출처** (01 · 01:09:42 ~ 01:11:04) ★

**등장 분자**: 아세틸-조효소 A(acetyl-CoA)

**내용**
- 아세틸기(CH₃CO–)가 조효소 A(CoA)의 **–SH(싸이올)**와 결합 → **싸이오에스터(thioester, CO–S)**.
- 한 분자 안에 **싸이오에스터, 아마이드, 이미다졸(강의 표현), 포스포릴** 등 여러 작용기가 공존.
- 조효소로서 아실기를 운반(Ch6: 판토텐산 B5 → CoA → 아실기 전달).

〔보충〕 CoA에 실제로 있는 것은 이미다졸이 아니라 아데닌(퓨린) 고리와 β-머캅토에틸아민, 판토텐산, 3′-포스페이트·피로인산이다. 강의에서 "이미다졸"이라 한 것은 아데닌 고리 안의 이미다졸 부분을 가리킨 것으로 보임.

- 같은 강의의 작용기 목록: 메틸·에틸·페닐, 카보닐(알데하이드/케톤), 카복실, 하이드록실, 에놀, 에터, 에스터, 아세틸, 산 무수물, 아미노, 아마이드, 이민, 시프 염기, 구아니디늄, 이미다졸, 설프하이드릴(싸이올), 이황화, 싸이오에스터, 포스포릴, 포스포안하이드라이드, 혼합 무수물.

## 10. 비공유 상호작용과 DNA 복제
**출처** (01 · 57:49 ~ 01:01:45) ★

**메커니즘**
1. 단백질·DNA·다당류의 **골격은 공유 결합**(펩타이드 결합, 포스포다이에스터 결합, 글리코사이드 결합)으로 만들어진 중합체.
2. 그러나 **기능하는 구조**는 비공유 상호작용(수소 결합, 이온 상호작용, 반데르발스, 소수성 효과)으로 만든다. 하나하나는 약하지만 **"쪽수로 승부"** → 합하면 강하다.
3. DNA 이중 나선의 두 가닥은 염기쌍 사이 **수소 결합(비공유)**으로 붙어 있어서 → **지퍼처럼 쉽게 열려** 한 가닥씩 복제될 수 있다. 공유 결합이었다면 열기 어렵다.

## 11. 진화적 기초의 분자 메커니즘
**출처** (02 · 53:24 ~ 01:01:03) ★

- **밀러-유리 실험**: 암모니아·메탄·수소·물 + 스파크(번개) + 고온 → **아미노산** 생성 → 생체 물질의 무기적 기원 가설.
- **RNA 세계(RNA world)**: RNA는 정보 저장(DNA 역할) + 촉매(효소 역할, 리보자임) 둘 다 가능 → 최초 생명은 RNA 기반 → 이후 불안정한 RNA 대신 **안정한 DNA**가 정보를, **20종 아미노산 조합으로 다양성이 큰 단백질**이 기능을 분담.
- **세포 내 공생(endosymbiosis)**: 산소를 잘 쓰는 호기성 세균이 원시 진핵세포에 들어와 **미토콘드리아**, 식물에서는 **엽록체**가 됨.
- **시아노박테리아** → 대기 산소 증가 → **오존층**(UV 차단) → 육상 진출. 산소는 초기 생명에게 독성이었지만 **최종 전자 수용체**로 쓰면 에너지를 훨씬 많이 얻으므로 호기성 생물이 번성.
- 에너지 생산의 본질 = **전자 흐름(electron flow) = 산화·환원**: 음식물에서 전자를 뽑아 ATP를 만들고, 전자는 최종적으로 가장 전자를 좋아하는 **O₂**에게 전달.

## 12. 세균 세포벽과 플라스미드
**출처** (01 · 50:47 ~ 53:47) ★

- **그람 양성**: **펩티도글리칸(peptidoglycan)** 층이 두꺼움. **그람 음성**: 막이 두 겹.
- **고세균**: 펩티도글리칸 대신 **슈도펩티도글리칸** → 극한 환경에 견딤.
- 대장균: 원형 유전체 DNA(핵양체, 막 한쪽에 부착) + **플라스미드** → 옆 세포에 쉽게 전달 → **항생제 내성 확산**의 경로.
- 항생제가 작동하는 원리: 사람과 세균이 "대부분 같지만 **다른 부분**"(예: 펩티도글리칸)을 표적으로 한다 → Ch3 D-알라닌, Ch6 페니실린, Ch7 펩티도글라이칸·라이소자임에서 구체화.
