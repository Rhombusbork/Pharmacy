## 1. 시스테인 산화와 이황화 결합
**출처** (05 · 43:31 ~ 45:48) ★★★

**등장 잔기**: 시스테인(Cys)의 **–SH** (= 싸이올기 = 설프하이드릴)

**메커니즘**
1. Cys는 세린과 모양이 비슷(CH₂–OH vs CH₂–**SH**)하지만 성질이 완전히 다르다: **–SH는 반응성이 매우 높다**.
2. 그래서 **활성산소(ROS)**가 생기면 **가장 먼저 반응하는 것이 Cys의 SH**.
3. **환원 상태**: –SH (전자를 충분히 가짐).
4. **산화**: 두 Cys가 각각 **H와 함께 전자를 잃음** → **–S–S– (이황화 결합, disulfide bond)**, 공유 결합.
5. **환원**: 전자를 받아 다시 –SH, –SH로 돌아갈 수 있다(가역).

**왜 중요한가**: 단백질 구조에는 공유 결합이 거의 없는데, **이황화 결합은 예외적으로 구조를 공유 결합으로 묶는 매듭**.
- 분비 단백질(인슐린, RNase A 등)에 많음 — 세포 밖은 가혹해서 접힘이 쉽게 풀리니까(06).
- 케라틴 교차 결합·파마(Ch4), PDI(Ch4), 안핀슨 실험의 머캅토에탄올(Ch4)로 이어짐.

## 2. Ser/Thr/Tyr 인산화
**출처** (05 · 42:54 ~ 44:26), (05 · 58:38) ★★

- **–OH를 가진 아미노산 3개: 세린, 트레오닌, 타이로신**.
- 이 OH에 **인산기가 붙는다(인산화, phosphorylation)** → 단백질 기능 조절의 대표 수단.
- → Ch4 p53 N-말단의 인산화·메틸화·아세틸화·유비퀴틴화로 기능 미세 조절.
- 〔보충〕 인산화 효소 = 카이네이스(kinase), 제거 = 포스파테이스(phosphatase, Ch6 용어).

## 3. γ-카복시글루탐산
**출처** (05 · 54:54 ~ 57:22) ★★★

**등장 잔기**: 글루탐산(Glu)의 곁사슬

**메커니즘**
1. Glu: α 탄소 → β → **γ 탄소**에 COO⁻가 하나 있음.
2. **γ 탄소에 COO⁻가 하나 더** 붙음 → **γ-카복시글루탐산(γ-carboxyglutamate, Gla)**.
3. 음전하 2개 → 음전하가 훨씬 강해짐 → **Ca²⁺와 결합**.
4. **혈액 응고(blood coagulation)에 관여하는 단백질**이 이 변형 아미노산을 가진다.

〔보충〕 이 γ-카복실화 효소는 **비타민 K**가 필요 → 와파린(비타민 K 길항제)이 항응고제로 작용하는 원리. 프로트롬빈 등이 해당.

## 6. 셀레노시스테인·피롤라이신
**출처** (05 · 57:22 ~ 58:38) ★★

- **셀레노시스테인**: 시스테인의 황(S) 자리에 **셀레늄(Se)**. 기본 20개는 아니지만 **유전자에 암호화**되어 있음 → **21번째 아미노산**. 셀레노시스테인이 꼭 들어가야 하는 단백질이 있다.
- **피롤라이신**: 라이신에 고리 구조가 추가. 사람에는 없고 일부 생물에만, 유전자에 암호화 → **22번째**.
- 〔보충〕 셀레노시스테인은 UGA(원래 종결 코돈)를 특별한 신호 서열과 함께 읽어 삽입된다. 대표 효소: 글루타싸이온 퍼옥시데이스.
- 단백질에 안 들어가는 대사 중간체: **오르니틴, 시트룰린**(요소 회로, Ch6 DFMO에서 오르니틴 재등장).

## 7. D-알라닌과 세균 세포벽
**출처** (05 · 25:06 ~ 26:41) ★★

1. 사람은 L-아미노산만 쓰지만, **세균 세포벽의 펩티도글리칸에는 D-알라닌**이 들어간다.
2. 이유: L형이면 숙주(사람) 효소가 분해할 수 있으니 **D형을 써서 보호**하도록 진화.
3. 이 차이를 역이용 → 사람에게는 독성이 없고 **세균만 죽이는 항생제**.
- 〔보충〕 반코마이신은 펩티도글리칸 전구체 끝의 **D-Ala-D-Ala**에 결합해 교차 결합을 막는다. 페니실린은 Ch6·Ch7 문서 참고.

## 8. L형만 쓰는 이유
**출처** (05 · 21:34 ~ 28:00) ★

- 글라이신(R = H)을 뺀 모든 아미노산의 α 탄소는 **키랄 중심** → L/D 거울상 이성질체.
- L/D는 빛의 회전 방향이 아니라 **절대 배열**(COO⁻를 위로 그렸을 때 α-아미노기가 왼쪽=L)로 정한다.
- 물리적 성질은 같지만 생체에서는 다른 분자로 인식.
- **단백질을 만드는 것도 단백질(과 RNA)**이고, 이 합성 기구가 **L형만 입체 특이적으로 인식**하기 때문. 초창기에 왜 L형이 선택됐는지는 모르지만 진화적으로 보존됨.
- → Ch4: L-아미노산이라서 **오른손 α-나선**이 된다(D형이 섞이면 R기가 안쪽으로 향해 서로 방해).

## 9. 곁사슬 성질과 단백질 속 위치
**출처** (05 · 28:00 ~ 53:30) ★★

| 그룹 | 아미노산 | 단백질 속에서의 역할 |
|---|---|---|
| 비극성 지방족 | Gly, Ala, Pro, Val, Leu, Ile, Met | **소수성 효과** → 구상 단백질의 **코어**(뼈대). **막 단백질**의 지질과 닿는 면 |
| 방향족 | Phe, Tyr, Trp | 소수성. Tyr·Trp는 280 nm 흡광 |
| 극성 비전하 | Ser, Thr, Cys, Asn, Gln | Ser·Thr(·Tyr) **인산화**, Cys **이황화 결합** |
| 양전하(염기성) | Lys(ε-아미노기), Arg(구아니디노기), His(이미다졸) | 염다리, His는 중성 pH에서 일부만 양전하 |
| 음전하(산성) | Asp, Glu | 염다리, Glu → γ-카복시글루탐산 |

- **가지 사슬 아미노산(BCAA)**: Val, Leu, Ile — 대사적으로도 따로 취급.
- His의 R기 pKa 6.0: pH 7에서는 **전하 없는 형태가 주(major)**라 교재 구조식에 + 표시를 안 했지만, 일부는 양전하라서 양전하 그룹에 분류.
- 코어에 소수성 아미노산이 없으면 3차 구조가 생기기 어렵다(강의 강조).

## 10. 글라이신과 프롤린
**출처** (05 · 29:20 ~ 31:51) ★★

- **글라이신**: R = H, 가장 작음 → **유연성이 너무 큼** → α-나선에 들어가면 나선이 깨짐. 콜라겐에서는 작아서 삼중 나선 코어에 꼭 들어감(Ch4).
- **프롤린**: R기 탄소가 **아미노기와 공유 결합해 고리** → 회전 불가, **너무 단단함** → α-나선을 깨고, β-턴을 만든다(Ch4).

## 11. pKa의 환경 의존성
**출처** (05 · 01:02:50 ~ 01:05:21) ★★

1. 아세트산의 –COOH pKa 4.8 vs 글라이신의 α-COOH pKa **2.34** → 약 100배 더 잘 이온화.
   - 이유: 옆의 **α-NH₃⁺(양전하)**가 COO⁻를 안정화.
2. 메틸아민 –NH₃⁺ pKa 10.6 vs 글라이신의 α-아미노기 pKa **9.60**.
   - 이유: 옆의 카복실기 영향.
3. **요지**: pKa는 절대값이 아니라 **주변에 어떤 기가 있느냐**에 따라 변한다. 3차 구조에서 주변 아미노산에 따라 곁사슬 pKa도 바뀐다 → 효소 활성 부위 잔기 pKa가 교과서 값과 다를 수 있는 이유.

- 등전점: 글라이신 pI = (2.34 + 9.60)/2 = **5.97** → 이 pH에서 전기영동 시 움직이지 않음. 글루탐산 pI = (pK₁ + pKR)/2 = **3.22**, 히스티딘 pI = (pKR + pK₂)/2 = **7.59**.

## 14. 서열과 진화
**출처** (06 앞부분) ★

- **컨센서스 서열**: 여러 종에서 보존된 자리 = 선택압을 견딘 필수 자리.
- **시그니처 서열**: 특정 생물군에만 있는 서열. **EF-Tu**(단백질 합성 인자)의 특정 서열이 세균에는 없고 고세균·진핵생물에는 있음 → 고세균이 진핵생물에 더 가깝다는 근거.
- **수평적 유전자 전달**: 플라스미드, 접합(conjugation), 박테리오파지로 외부 유전자 유입 → 진화 분석에서 따로 고려.
- 메리필드 고체상 펩타이드 합성(비드에 붙여 하나씩 붙이고 씻기 반복), 에드만 분해법 → 질량분석.
