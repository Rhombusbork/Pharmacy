## 1. 히스티딘 이미다졸 pKa 6.0
**출처** (04 · 45:57 ~ 48:36), (05 · 48:36 ~ 50:58) ★★★

**등장 잔기**: 히스티딘(His)의 **이미다졸 고리(imidazole ring)** 곁사슬

**메커니즘**
1. 이미다졸 곁사슬의 pKa ≈ **6.0** → 완충 범위 pKa ± 1 = **pH 5~7** → 중성 pH가 들어간다.
2. 20개 아미노산 중 **중성 pH 근처에서 양성자를 얻고 잃을 수 있는 곁사슬은 히스티딘뿐**.
3. 그래서 pH가 조금만 변해도 His가 **양성자를 받느냐(+) / 내놓느냐(중성)**가 바뀌고, 이것이 단백질 기능의 스위치가 된다.
4. 결과: 많은 효소의 **활성 부위(active site)**에 His가 들어가 **양성자를 주고 빼는 반응(일반 산-염기 촉매)**을 한다.

**이 원리가 다시 나오는 곳**
- Ch5 보어 효과: β **His146**이 양성자를 받아 Asp와 염다리 → T 상태
- Ch6 키모트립신: **His57**이 Ser195의 H를 빼앗음 (최적 pH 8의 이유)
- Ch7 만노스-6-인산 수용체: 리소좀 pH 4~5에서 His가 양성자화 → 리간드 방출
- Ch5 마이오글로빈·헤모글로빈: 근위 His(F8), 원위 His(E7)

**주의(강의 강조)**: 단백질 안에서는 α-아미노기·α-카복실기가 펩타이드 결합에 쓰여 이온화가 안 되므로, **곁사슬(R기)의 pKa**가 중요하다.

## 2. 히스티딘 적정 순서
**출처** (04 · 48:36 ~ 50:55) ★★

pH가 아주 낮을 때 히스티딘: α-NH₃⁺, α-COOH, 이미다졸–H⁺ → 전하 **+2**
NaOH를 넣으며 양성자가 빠지는 순서:
1. **α-COOH** (가장 산성, pK₁ ≈ 1.82) → +1
2. **이미다졸 H⁺** (pKR ≈ 6.0) → **0** (+1과 0의 비율이 50:50인 pH가 6.0)
3. **α-NH₃⁺** (pK₂ ≈ 9.17) → −1

- 등전점 pI = (pKR + pK₂)/2 = (6.0 + 9.17)/2 ≈ **7.59** (05 · 01:06:43)

## 3. 중탄산 완충계
**출처** (04 · 51:50 ~ 01:01:06) ★★★

**등장 분자**: CO₂, H₂CO₃(탄산), HCO₃⁻(중탄산, 베이킹소다의 그것)

**반응**
```
CO₂(조직에서 산화로 생성) + H₂O ⇌ H₂CO₃ ⇌ H⁺ + HCO₃⁻
```

**메커니즘**
1. 영양소 산화로 생긴 CO₂가 일부 물에 녹으면 곧바로 H₂CO₃ → H⁺ + HCO₃⁻.
2. **CO₂가 쌓이면**(환기 부족) → 르샤틀리에 원리로 오른쪽 이동 → H⁺ 증가 → **pH 하강**.
3. **호흡을 많이 하면**(CO₂ 제거) → 왼쪽 이동 → H⁺ 감소 → **pH 상승**.
4. **신장**이 HCO₃⁻의 배출·보유(retention)를 조절 → 또 하나의 손잡이.
5. pH 저하는 **뇌간**이 감지 → 호흡량을 늘려(과호흡) pH를 올린다.

**계산**
- 결합된 pKa ≈ **6.1** (Ka와 Kh를 합친 값)
- 37 °C 정상 혈액: H₂CO₃ 1.2 mM, HCO₃⁻ 24 mM
- pH = 6.1 + log(24/1.2) = 6.1 + log 20 ≈ **7.4**

**시험 포인트 (강의에서 직접 질문함)**: "pKa 6.1이면 완충 범위가 5.1~7.1인데 왜 7.4를 지키는 주 완충계일까?"
→ **열린 계(open system)**이기 때문. CO₂는 폐로, HCO₃⁻는 신장으로 **외부와 교환**하면서 능동적으로 조절할 수 있다. 히스티딘·인산은 물질 양을 바로 바꿀 수 없는 닫힌 완충계.

## 4. 과호흡과 알칼리증
**출처** (04 · 55:31 ~ 56:56) ★★

1. 공황 발작 → 호흡이 가빠짐(과호흡) → CO₂가 너무 빨리 제거.
2. → H⁺ 감소 → 혈액 pH 상승 = **알칼리증(alkalosis)** → 어지러움, 손발 저림, 근육·사고 기능 저하.
3. **종이봉투**에 대고 숨쉬기 → 내쉰 CO₂를 다시 들이마심 → pH 상승을 막는다.

- pH < 7.4 산증(acidosis), pH > 7.4 알칼리증. 7.4에서 ±0.1만 벗어나도 위험.

## 5. 당뇨병성 케톤산증
**출처** (04 · 01:04:32 ~ 01:06:05) ★★

**등장 분자**: **β-하이드록시뷰티르산**, **아세토아세트산** (= 케톤체, ketone body)

1. 당뇨 환자는 혈당을 에너지원으로 쓰지 못함 → 혈당이 높아짐.
2. 대신 **지질(지방)**을 분해해 에너지를 얻으려 함 → **간**에서 케톤체 생성.
3. 케톤체는 **산(acid)** → 대량 생성되면 혈액 pH 저하 → **산증** → 혼수, 생명 위협.

〔보충〕 아세톤도 케톤체에 속하며 날숨의 과일 냄새 원인. 자세한 대사 경로는 2학기.

## 7. 효소–기질 결합과 탈용매화
**출처** (03 · 45:23 ~ 48:09), (10 Ch6 "탈용매화"에서 재등장) ★★

**메커니즘**
1. 기질도, 효소도 각각 **물 분자(수화층, hydration shell)**에 둘러싸여 있다.
2. 기질이 활성 부위에 붙으려면 **먼저 이 수화층을 깨야** 한다(탈용매화, desolvation).
3. 그러므로 **기질–효소 상호작용 > 기질–물, 효소–물 상호작용**이어야 결합이 일어난다.
4. 결합하면 자유도가 묶여 있던 물 분자들이 풀려나 **엔트로피 증가** → 결합 방향이 열역학적으로 유리.
5. 반대로 효소 활성 부위에 물이 너무 강하게 붙어 있으면 기질이 결합할 수 없다.

## 8. 고정된 물과 양성자 전달
**출처** (03 · 50:44 ~ 52:30), (04 · 15:26 ~ 19:39) ★★

**① 단백질 속 고정된 물**
- 단백질 구조 안에 물 분자가 **딱 고정(fix)**되어 있는 경우가 있다(그림의 빨간 점).
- 이 물 사슬을 따라 **양성자(H⁺)를 전달(transfer)**할 수 있다 → 물이 단백질 기능의 일부(구조적 역할).
- 〔보충〕 교재 그림은 사이토크롬 f의 "양성자 통로(proton wire)" 예.

**② 양성자 도약(proton hopping)**
1. 물이 이온화되면 H⁺는 혼자 있지 못하고 옆 물과 결합 → **하이드로늄 이온(H₃O⁺)**.
2. H⁺ 자체가 멀리 헤엄쳐 가는 게 아니라, 수소 결합으로 연결된 물 분자들 사이에서 **결합이 연쇄적으로 바뀌며** 멀리 떨어진 물에서 H⁺가 나타난다.
3. 그래서 양성자의 이동은 Na⁺, Cl⁻ 같은 이온보다 **훨씬 빠르고**, 용액 전체의 pH가 빠르게 동기화된다.

## 9. 소수성 효과
**출처** (03 · 39:02 ~ 45:23) ★★

**메커니즘**
1. 순수한 물: 수소 결합 파트너를 **피코초 단위로 바꾸며** 자유롭게 움직임 → 엔트로피 높음.
2. 지방산의 **탄화수소 꼬리(소수성)**가 들어오면, 그 주변 물은 수소 결합을 못한 채 꼬리를 **둘러싸 갇힘(케이지)** → 물의 엔트로피 감소.
3. 소수성 분자들이 **흩어져 있으면** 각각을 둘러싼 물이 많아 손해가 큼.
4. 소수성 분자들을 **한데 모으면** 갇히는 물 분자 수가 줄어 → **물의 엔트로피 손실 최소화**.
5. 이 결과로 소수성 물질이 모이는 현상 = **소수성 효과(hydrophobic effect)**.

**강의 강조**: "소수성끼리 결합을 잘한다"는 해석은 **틀림**. 원인은 **물(용매)의 엔트로피**. "소수성 결합"이 아니라 **"소수성 효과"**라고 써야 한다.

**다시 나오는 곳**: 구상 단백질의 소수성 코어(Ch4), 케라틴 코일드 코일 접촉면(Ch4), 아밀로이드 응집(Ch4), HbS 섬유(Ch5), 변성 시 소수성 부위 노출 → 침전(Ch4).

**NaCl 용해의 열역학 (03 · 29:48 ~ 33:29)**: 녹으면 Na⁺·Cl⁻의 무작위도 ↑(크게), 수화층에 갇힌 물의 무작위도 ↓(작게) → 합해서 ΔG < 0 → 잘 녹는다. Na⁺에는 물의 O(δ⁻)가, Cl⁻에는 물의 H(δ⁺)가 향한다.

**O₂·CO₂·N₂가 물에 잘 안 녹는 이유 (03 · 36:26)**: 녹으면 ΔH 증가, ΔS 감소 → ΔG가 음이 되지 못함 → 그래서 **헤모글로빈**이 필요(Ch5).

## 10. 유전 상수와 이온 상호작용
**출처** (03 · 33:29 ~ 36:26), (04 · 01:46 ~ 04:00) ★★

- 쿨롱 힘: **F = Q₁Q₂ / εr²**
- **ε (유전 상수, dielectric constant)** = 전하 차폐 능력. 물 **78.5**, 벤젠 **4.6**.
- 물 속: ε가 크다 → Na⁺–Cl⁻ 인력 약화 → 잘 녹음.
- 벤젠(소수성 환경): ε가 작다 → 이온 사이 인력 강함 → 안 녹음.

**연결 (06 Ch4)**: 단백질 **바깥(물)**에서는 전하가 물에 가려져 염다리가 약하고, **소수성 코어**에서는 ε가 벤젠처럼 낮아져 **염다리(이온쌍)가 강해진다** → 염다리는 주로 코어에서 형성. 강의에서 "단백질 접힘에서 이 특성이 중요하게 작용한다"고 예고.

## 11. 생체 수소 결합
**출처** (03 · 05:22 ~ 27:02) ★★

**물 자체**
- O의 전기음성도가 커서 H는 δ⁺, O는 δ⁻ → 쌍극자, 사면체 구조.
- 물 1분자: 주개 2 + 받개 2 = 최대 **4개** 수소 결합. 얼음 = 4개(듬성한 격자 → 밀도 낮아 뜬다), 액체 = 평균 **3.4개**.
- NH₃는 주개 3·받개 1, HF는 주개 1·받개 3 → 불균형이라 비효율.
- 수소 결합 해리 에너지 ≈ **23 kJ/mol** (공유 결합의 약 1/20). 약 10%는 공유 결합 성질, 90%는 정전기적 인력.

**생체 분자에서**
- 수소 결합 가능: **C=O, –OH, –NH** (O, N이 있을 때). **C–H는 불가**(C와 H의 전기음성도가 거의 같음).
- **펩타이드 결합의 C=O와 N–H** 사이 수소 결합 → α-나선, β-시트(Ch4).
- **DNA 상보적 염기쌍**: A–T, G–C는 특정 원자가 **특정 거리**에서만 수소 결합할 수 있어서 짝이 정해진다.
- **방향성**: 일직선(H 기준 180°) → 강함 / 꺾인 각도 → 약함. → Ch4에서 **역평행 β-시트(일직선, 강함) vs 평행 β-시트(꺾임, 약함)**의 근거.

## 12. 미셀·리포솜·LNP
**출처** (03 · 43:47 ~ 46:52) ★

- **미셀(micelle)**: 친수성 머리는 바깥(물), 소수성 꼬리는 안쪽 코어 → 구 형태. 지질 소화(쓸개즙)·화장품 에멀전.
- **리포솜(liposome)**: 꼬리가 지질 이중층을 이루고, 안쪽에 **친수성 공간**이 있는 구조 → 불안정한 RNA를 실어 세포에 전달.
- **mRNA 백신의 지질 나노입자(LNP)**도 같은 원리.
- 양친매성 예: 포스파티딜콜린(세포막), 세제(계면활성제).

## 13. 효소의 최적 pH
**출처** (04 · 01:01:06 ~ 01:04:32) ★

- pH 7.4·37 °C가 중요한 이유: 효소와 단백질이 구조를 제대로 이루는 **최적 조건**이기 때문.
