# A. 구조를 만드는 힘

## 1. 펩타이드 결합의 공명
**출처** (06) ★★

1. 펩타이드 결합(C–N)은 원래 단일 결합이지만, **공명(resonance)**으로 전자가 오가며 **부분적 이중 결합** 성질.
2. 결과 ① **회전 불가** → 주변 **6개 원자가 한 평면**. ② 길이 **1.32 Å** (일반 C–N 단일 결합 1.49 Å보다 짧음).
3. 결과 ③ **부분 전하**: C=O 쪽 O는 δ⁻, N–H 쪽 H는 δ⁺ → 2차 구조의 **수소 결합**을 만드는 근거.
4. 회전각: **φ** = N–Cα, **ψ** = Cα–C, **ω** = 펩타이드 결합 자체(0° 또는 180°, 대부분 **트랜스**).
5. φ, ψ는 자유롭지만 둘 다 0°처럼 **입체 장애**가 생기는 조합은 불가 → **라마찬드란 도표**(알라닌 기준). 왼손 α-나선은 거의 없음. 글라이신은 너무 유연해 허용 영역이 넓다. 실제 예: 피루브산 카이네이스의 φ/ψ 분포.

## 2. α-나선
**출처** (06), (07 · 01:36 ~ 03:09) ★★★

1. L-아미노산이므로 **오른손 나선**(D형이면 R기가 안쪽을 향해 서로 방해).
2. 한 바퀴 **3.6 잔기**, 피치(pitch) **5.4 Å**.
3. **n번째 잔기의 C=O 산소 ··· n+4번째 잔기의 N–H 수소** 사이 수소 결합(펩타이드 골격끼리)이 4잔기마다 규칙적으로 반복되어 안정화.
4. **곁사슬 배치 규칙**: 위에서 내려다볼 때 가까이 오는 잔기끼리 같은 전하면 반발 → 불안정. 반대 전하면 상호작용·**염다리**, 소수성끼리면 **소수성 효과**로 안정.
5. **나선 파괴자**: **프롤린**(고리로 고정, 회전해야 할 곳에서 꺾임), **글라이신**(너무 유연). 알라닌 기준 파괴 경향 수치: Gly ≈ 1 이상, Pro ≈ 3 이상.
6. **나선 쌍극자**: 나선 전체가 한쪽 끝은 +, 다른 끝은 −. 이를 상쇄하려고 **N-말단 쪽에 음전하 아미노산, C-말단 쪽에 양전하 아미노산**이 위치.

〔보충〕 쌍극자 방향은 N-말단 쪽이 δ⁺, C-말단 쪽이 δ⁻. 그래서 N-말단 근처에 Asp/Glu, C-말단 근처에 Lys/Arg.

## 3. β-시트와 β-턴
**출처** (06), (08 · 00:06) ★★★

**β-시트**
- β-가닥(지그재그)이 병풍처럼 모인 것. 가닥 간 **C=O ··· N–H 수소 결합**.
- **역평행(antiparallel)**: 수소 결합이 **일직선** → 강함.
- **평행(parallel)**: 수소 결합이 **약간 꺾임** → 상대적으로 약함. (Ch2 수소 결합 방향성)

**β-턴 형성 규칙**
1. **2번 위치에 프롤린** → 딱 꺾임.
2. **3번 위치에 글라이신** → 유연해서 꺾임 가능.
3. 그런데 프롤린이 β-턴을 만들려면 펩타이드 결합이 **시스(cis)**여야 한다. 일반 펩타이드 결합은 트랜스지만 **프롤린은 약 6%가 시스**.
4. 트랜스 → 시스 전환은 **자발적으로 잘 일어나지 않음** → 효소 **프롤릴 이성질화효소 = 펩티딜 프롤릴 시스-트랜스 이성질화효소(PPIase)** 필요.
5. 그래서 특정 단백질은 정확한 형태를 위해 **PPIase 활성이 필수**.

**CD 분광법(원편광 이색성)**: 190~250 nm. α-나선 → 208·222 nm, β → 약 216 nm 특징 패턴. 활용: Lys를 다른 아미노산으로 치환한 뒤 CD로 2차 구조가 유지되는지 확인 → "구조는 그대로인데 기능만 바뀌었다"를 판단.

## 4. 염다리와 단백질 내부
**출처** (06) ★★

1. 예: **라이신의 ε-아미노기(+)**와 **–CH₂–COO⁻(Asp, −)**가 정전기적으로 끌어당김 = **이온쌍 = 염다리(salt bridge)**.
2. 단백질 **바깥(물)**: 물이 전하를 가려(ε ≈ 80) 염다리가 잘 안 생김.
3. 단백질 **안쪽(소수성 코어)**: 유전 상수가 벤젠처럼 크게 떨어짐 → 전하 차폐가 사라져 **강하게 끌어당김**.
4. 그래서 염다리는 **코어에서 형성되기 쉽다**. (쿨롱 F = Q₁Q₂/εr²)

**3차 구조의 힘 정리 (06)**: 2차 구조는 **수소 결합**이 핵심, 구형 3차 구조는 **소수성 효과**가 핵심, 바깥의 **수화층**도 중요, 분비 단백질은 **이황화 결합**으로 매듭. 서열이 주어지면 **열역학적으로 가장 안정한 구조**로 접힌다.

# B. 섬유상 단백질

## 5. α-케라틴과 파마
**출처** (07 · 01:36 ~ 07:45) ★★★

**구조 메커니즘**
1. 기본 단위: **오른손 α-나선**.
2. 두 개가 서로 꼬여 **코일드 코일(슈퍼코일)** — 꼬이는 방향은 **왼손**. 단위(오른손)와 꼬임(왼손)이 반대라서 더 단단히 꼬인다.
3. 두 나선의 **접촉 부위**에 **Ala, Val, Leu, Ile, Met, Phe** 같은 소수성 아미노산 → **소수성 효과**로 결합.
4. 모여서 원섬유(protofilament) → 원섬유다발(protofibril) → **중간섬유(intermediate filament)**.
5. 더 강하게: **Cys 간 이황화 결합으로 교차 결합(cross-link)** → 끊어지기 힘든 공유 결합. 코뿔소 뿔은 이황화 결합이 아주 많아 매우 단단.

**파마의 메커니즘**
1. **환원제**(냄새의 원인)로 이황화 결합(–S–S–)을 **환원** → –SH, –SH로 끊음.
2. 머리카락을 물리적으로 **말아(curling)** → 다른 –SH끼리 가까워짐.
3. **산화제**로 다시 산화 → **새 위치에 이황화 결합** 형성 → 컬 고정.

## 6. 콜라겐과 괴혈병
**출처** (07 · 07:45 ~ 15:21) ★★★

**구조**
1. 콜라겐 사슬은 α-나선이 아닌 고유의 **왼손 나선**.
2. 세 가닥이 **오른손으로 꼬인 삼중 나선** (케라틴과 정반대: 케라틴은 오른손 단위·왼손 꼬임).
3. 서열: **Gly-X-Y 반복**. X, Y엔 주로 **Pro, Lys**(상당수가 하이드록실화).
4. **글라이신이 반드시 3번마다**: 위에서 보면 Gly가 삼중 나선 **안쪽**에 위치. Gly의 R기는 H로 가장 작아서 **촘촘한 코어**가 가능. → 결합 조직을 지지, 약하면 혈관 파열·조직 이탈.
5. Pro → **4-하이드록시프롤린**, Lys → 하이드록시라이신. –OH가 **수소 결합**을 만들어 강도 유지.
- 우리 몸 단백질의 약 **30%**. 삼중 나선을 밝힌 사람: 라이너스 폴링(강의 표현).

**프롤릴 하이드록실레이스 반응 (07 · 13:08 ~ 15:21)**
1. 효소: **프롤릴 하이드록실레이스(prolyl hydroxylase)**, 프롤린 4번 탄소에 –OH를 붙인다.
2. 기질: **α-케토글루타르산 + O₂** → –OH의 **O는 산소 분자에서** 온다.
3. 필요한 금속: **Fe²⁺ (페러스 이온)**. Fe²⁺는 전자 친화도가 커서 쉽게 산화되어 **Fe³⁺(페릭)**로 바뀜 → 효소 불활성.
4. **아스코르브산(비타민 C)**이 Fe를 **환원된 Fe²⁺ 상태로 유지**시켜 준다(보조인자).

**괴혈병(scurvy)**: 비타민 C 결핍 → 하이드록실화 실패 → 콜라겐이 단단하지 않음 → 잇몸 출혈·치아 탈락, 멍이 쉽게 듦(혈관), 뼈 약화, 상처 치유 지연. 다이어트·만성 음주에서 아직도 발생.

〔보충〕 반응 부산물로 α-KG → 숙신산 + CO₂. 아스코르브산은 반응이 정상 순환하지 않을 때 Fe를 다시 환원하는 역할.

## 7. 라이실 옥시데이스
**출처** (07 · 15:21 ~ 18:10) ★★★

1. 수소 결합만으로는 한계 → **공유 교차 결합**이 필요.
2. 효소 **라이실 옥시데이스(lysyl oxidase)**, 보조인자 **구리(Cu)**.
3. Lys 곁사슬 **ε-1차 아민(–NH₂)** → NH₃가 빠지고 **알데하이드(–CHO)** → **알리신(allysine)**.
4. 알리신의 알데하이드는 반응성이 커서, 옆의 온전한 Lys의 ε-아미노기와 반응 → **교차 결합(공유 결합)**.
5. 효소가 없거나 억제되면 콜라겐 구조 이상 → 뼈 등 형태 유지 곤란.
6. **노화**: 교차 결합이 계속 쌓여 **경직도(stiffness) 증가 → 탄력 감소**의 한 원인으로 생각됨.

## 8. 콜라겐병증
**출처** (07 · 18:10 ~ 20:51) ★★

- 콜라겐 유전자 23개 = 파라로그 → 각각 다른 위치·기능.
- **골형성 부전증(osteogenesis imperfecta)**: **1형 콜라겐**, 유전자 **COL1A1 / COL1A2** 돌연변이 → 뼈가 단단하게 안 만들어짐 → 출생 시 골절, 심하면 사망.
- **엘러스-단로스 증후군(Ehlers-Danlos)**: **5형 콜라겐**, **COL5A1 / COL5A2**.
- 명명: 단백질 "collagen type I", 사람 유전자는 대문자 이탤릭 *COL1A1*.

〔보충〕 골형성 부전증에서 흔한 돌연변이는 Gly-X-Y의 **Gly가 다른(큰) 아미노산으로 바뀐 것** → 삼중 나선 코어가 깨짐(6번의 Gly 논리와 연결).

## 9. 엘라스틴과 α1-항트립신
**출처** (07 · 20:51 ~ 28:07) ★★★

**엘라스틴·데스모신**: 콜라겐(밧줄, 안 늘어남)과 달리 **탄력**. 엘라스틴 Lys → 라이실 옥시데이스 → **알리신**, 4개가 모여 벤젠 고리 같은 **고리형 공유 교차 결합 = 데스모신** → 늘어났다 줄어듦. 폐·동맥에 중요.

**α1-항트립신(AAT) – 엘라스테이스 – 폐기종**
1. **호중구(neutrophil)**가 침입한 세균을 분해하려고 **엘라스테이스(elastase)**를 분비(세균 세포벽 등 비슷한 구조의 단백질을 분해).
2. 아무 때나 작동하면 정상 **엘라스틴(폐포)**까지 분해 → 안전장치 **α1-항트립신(AAT)**이 엘라스테이스의 **활성 부위를 가려(masking) 억제**. AAT는 폐포에 존재해 폐 손상을 막는다.
3. **유전적 결핍**: AAT의 **342번 Glu(−) → Lys(+)** (성질이 정반대) → 기능 상실 → 폐포 엘라스틴 분해 → **폐기종(emphysema)**. 미국 폐기종 환자의 2~5%. **한국인에게는 이 돌연변이가 없음**.
4. 같은 돌연변이 AAT는 구조가 제대로 안 접혀 **생산지인 간에 쌓임** → **간경화(liver cirrhosis)**.
5. **흡연**: AAT의 **358번 메싸이오닌(Met358)이 산화** → 엘라스테이스를 억제하지 못함 → 폐기종.

〔보충〕 Glu342Lys = "Z 변이(PiZZ)". Met358은 AAT의 반응 중심(엘라스테이스가 미끼로 자르는 자리)이라 산화되면 엘라스테이스가 인식하지 못한다.

**출처** (07 · 28:07 ~ 29:26) ★★

# C. 구상 단백질과 접힘

## 11. 구상 단백질의 코어
**출처** (07 · 29:26 ~ 37:58) ★★

- 같은 수의 아미노산: β(길쭉) → α-나선(짧고 두꺼움) → 구상(조밀).
- **마이오글로빈**(향유고래, 최초로 밝혀진 구조): α-나선 8개, **소수성 아미노산(노란색)은 코어**, 바깥엔 거의 없음. 코어가 무너지면 구조가 쉽게 와해. 가운데에 **헴**(근육의 O₂ 저장).
- **모티프(=폴드)**: 2차 구조 2개 이상의 조합(β-α-β 고리, β 헤어핀, α/β 배럴, β 배럴(항체)).
- **도메인**: 독립적으로 접히고 **자기 기능을 할 수 있는 최소 단위**(예: 잘라내도 Ca²⁺ 결합이 가능한 부분).
- 경험 규칙: 2차 구조가 **2층 이상**이어야 소수성 코어 형성 / α와 β는 다른 층 / 가까운 잔기끼리 구조 형성 / β는 대부분 오른손.
- **4차 구조**: 헤모글로빈 α₂β₂ 사량체(각각 = 원체, protomer).

## 12. 내재적 무질서 단백질 (p53)
**출처** (07 · 37:58 ~ 41:58) ★★

1. **p53**의 X선 구조에서 **N-말단, C-말단**은 구조가 안 보임 = 정해진 구조가 없음 = **IDP**.
2. 특징: **소수성 코어 없음**, **전하 아미노산이 많음**(이온 상호작용), **프롤린이 많음**(α-나선·β-시트를 모두 깸 → 무정형 유지).
3. 이유: 결합 파트너가 하나로 정해지지 않음 → **C-말단**에 사이클린 A, 시르투인, CBP 브로모도메인, S100B 등 다양한 단백질이 결합.
4. **N-말단**은 다양한 효소에 의해 **메틸화, 인산화, 아세틸화, 유비퀴틴화** → 기능이 미세 조절.

## 13. 변성과 카오트로픽 물질
**출처** (07 · 49:14 ~ 57:33) ★★

1. **RNase A**(RNA 분해 효소)·**아포마이오글로빈**(헴 뺀 마이오글로빈)으로 관찰: 온도를 올리면 어느 순간까지 버티다가 한꺼번에 펼쳐짐(unfolded) → **시그모이드 곡선**.
2. **카오트로픽 물질**: **구아니딘 염산염, 요소** — 질소가 많아 **수소 결합을 매우 잘함**. 단백질은 물과 적당히 수소 결합해야 구조가 서는데, 이들이 수소 결합을 **비정상적으로 다 가져가** → 변성, 효소 활성 상실.
3. 시그모이드 = **협동적(cooperative)** 구조 유지: 하나가 풀리면 와르르 무너진다(스위치처럼 on/off).
4. 변성 요인: 열, 극단적 pH, 유기 용매(물을 없앰 → 소수성 효과의 기반 제거), 카오트로픽 물질.
5. 변성되면 구상 단백질의 **소수성 코어가 노출** → 다른 단백질(또는 자기 자신)과 소수성 효과로 달라붙어 **침전**. 물을 끓여 먹는 이유(균 단백질 변성·침전).

## 14. 안핀슨 실험
**출처** (07 · 57:33 ~ 01:01:20) ★★★

**재료**: **RNase A** — 분비 단백질이라 **이황화 결합 4개**(Cys 8개).

**과정**
1. **요소(urea)** 처리 → 수소 결합을 끊어 접힘을 풀어 줌. 하지만 **이황화 결합(공유)**은 남음.
2. **2-머캅토에탄올**(β 탄소에 –SH, "머캅토") 처리 → –SH가 이황화 결합을 **환원**해 끊음. (같은 용도로 **DTT, 다이싸이오트레이톨**도 많이 씀)
3. → 형태가 완전히 풀리고 **활성 소실**.
4. **투석(dialysis)**으로 요소와 머캅토에탄올을 제거.
5. → 공기 중 산화로 이황화 결합이 다시 생기며 **천연 형태 회복 + 활성 회복**(거의 100%).

**의미**: Cys 8개가 무작위로 짝지으면 100가지 이상의 조합이 가능한데도 **올바른 짝으로 재생** → **아미노산 서열(1차 구조)이 3차 구조를 결정한다**. 노벨상.

## 18. 단백질 항상성
**출처** (07 · 44:57 ~ 49:14) ★★

1. 리보솜에서 mRNA → 폴리펩타이드 → 스스로 혹은 **샤페론** 도움으로 접혀 천연 단백질.
2. 열 등으로 접힘이 풀리면 **잘못 접힌 단백질**. 합성 중 많게는 **1/4**이 제대로 안 만들어짐.
3. 이런 단백질 → **유비퀴틴을 붙여(ubiquitin-proteasome system, UPS)** 프로테아솜에서 잘게 잘라 아미노산으로 재활용.
4. 분해되지 못하고 뭉치면 → 무정형 침전 / 올리고머 / β-시트 섬유 = **아밀로이드 원섬유**.
5. 응집체는 **자가포식(autophagy)**으로 처리될 수 있음.
6. 이 균형(합성·접힘·분해)이 **proteostasis**. 무너지면 질환.

# D. 접힘 이상 질환

## 19. 낭포성 섬유증 (CFTR ΔF508)
**출처** (08 · 01:52 ~ 04:38) ★★★

1. 원인 유전자/단백질: **CFTR** — **염화 이온(Cl⁻) 채널**, 막 단백질.
2. 막 단백질은 **ER에서 만들어져** 세포막으로 가야 한다.
3. 가장 흔한 돌연변이: **508번 페닐알라닌 결손(ΔF508)** — 염기 3개가 빠져 Phe 하나가 없어짐.
4. → **접힘 실패** → ER 품질 관리에 걸려 **ER 체류(ER retention)** → 세포막에 거의 못 감.
5. 정상: Cl⁻가 밖으로 나가며 Na⁺도 나가고 → **물이 따라 나가** 점액(특히 폐)을 촉촉하게 순환.
6. 이상: 수분 부족 → **점액이 두꺼워지고 정체** → 감염 증가, 폐·신장 등 **낭종(cyst) + 섬유화(fibrosis)**.

## 20. 아밀로이드 질환
**출처** (08 · 04:38 ~ 11:14) ★★★

**공통 메커니즘**
1. 정상 단백질이 접힘이 **부분적으로 풀림**.
2. **β-턴/β-시트 구조로 전환**.
3. 노출된 소수성 잔기(그림의 **페닐알라닌**)끼리 **소수성 효과**로 뭉침.

**질환별 원인 단백질**

|---|---|---|

## 21. 프라이온
**출처** (08 · 11:14 ~ 14:09) ★★
