# A. 촉매의 원리

## 1. 결합 에너지: NADPH–DHFR
**출처** (10 · 결합 에너지) ★★★

1. 효소가 반응을 10⁵~10¹⁷배 빠르게 하는 힘 = **결합 에너지(binding energy)**, 원천은 **비공유 상호작용**.
2. 예: **NADPH**가 **다이하이드로엽산 환원효소(dihydrofolate reductase, DHFR)** 활성 부위에 들어감.
3. NADPH 주위에 아미노산들이 배열되어 **수소 결합, 소수성 효과에 의한 상호작용, 이온 상호작용** 등 **모두 비공유 결합**으로 맞물림.
4. 맞물리며 에너지가 낮아짐 → **활성화 에너지 감소 → 속도 증가**. 생성물도 마찬가지로 결합.
5. 동시에 **특이성**: NADPH가 아닌 다른 물질은 이 자리에 맞지 않음 → 기질 특이성.

〔보충〕 DHFR은 다이하이드로엽산 → 테트라하이드로엽산(THF)을 만드는 효소로, **메토트렉세이트(항암제)·트라이메토프림(항생제)**의 표적. 그래서 교재가 예로 든다.

## 2. 전이 상태 결합과 유도 적합
**출처** (10 · 효소의 핵심 특성, 결합 에너지) ★★

1. 효소가 기질에 너무 강하게 붙으면 생성물로 바꿔 내보내기 어려움.
2. 그래서 효소가 **가장 강하게 결합하는 것은 전이 상태(transition state)** → 전이 상태를 안정화해 그쪽으로 유도하고, 바뀌면 곧바로 생성물 방출.
3. ES 복합체가 너무 안정하면(생성물보다 에너지가 낮으면) 반응이 오히려 어려움.
4. 그래서 **자물쇠-열쇠**가 아니라 **유도 적합**: 기질은 "적당히" 맞고, 효소 구조가 조금씩 바뀌어 전이 상태·생성물에 맞춰지고 방출.
5. 비유(강의): 효소가 사람(기질)의 팔을 올려 옷을 벗김(생성물). ES가 가장 안정, 옷을 빼는 데(전이) 에너지, 생성물 방출에도 에너지.
6. **효소가 큰 이유**: 작은 활성 부위를 정교하게 만들려면 큰 구조가 필요.
- 이 원리 → **전이 상태 유사체** 약물(13번 HIV 프로테에이스 저해제).

## 3. 탈용매화와 엔트로피 감소
**출처** (10 · 탈용매화와 엔트로피 감소) ★★

- **탈용매화**: 기질·효소 모두 물에 싸여 있음 → 물 껍질을 벗겨야 상호작용 → **결합 에너지 > 탈용매화 에너지**여야 함. (Ch2 문서 7번)
- **엔트로피 감소(근접·배향)**: 떨어진 분자끼리의 반응 속도를 1이라 하면 가까울수록 기하급수적으로 증가 → 효소는 기질들을 **한곳에 모아** 엔트로피 비용을 대신 치러 준다.

## 4. 촉매 메커니즘 3가지
**출처** (10 · 촉매 메커니즘) ★★

1. **일반 산-염기 촉매**: 아미노산 **곁사슬(R기)**이 양성자를 주고(산) 받음(염기). 예: 키모트립신 His57.
2. **공유 결합 촉매**: A–B를 자를 때 효소(X)가 B 대신 A와 **잠깐 공유 결합**해 B를 떼어 낸 뒤, 다시 A를 놓아 줌. 예: 키모트립신 Ser195 아실-효소 중간체.
3. **금속 이온 촉매**: 금속 이온이 기질의 **방향·위치를 잡고**, 전하를 안정화하며, **산화-환원**에 관여. 효소의 약 1/3이 금속 이온 사용. 예: 에놀레이스 Mg²⁺.

## 5. 효소 없는 반응 속도
**출처** (10 · 효소의 촉매 작용과 반응 속도) ★

- **CO₂ 수화**: 효소 없이 반감기 5초 → **탄산탈수효소(carbonic anhydrase)**가 **10⁷배** 촉진. 대사로 생긴 CO₂가 안 녹으면 기포 → 치명적.
- **글라이신 탈카복실화**: 반감기 약 **11억 년**.
- 효소 = 화학적 시간 척도를 **생물학적 시간 척도**로 바꿈. **평형은 바꾸지 않음**.
- 약학적 중요성: FDA 승인 약물의 약 **40%가 효소 표적**(예: 엘리퀴스).

〔보충〕 탄산탈수효소는 활성 부위 **Zn²⁺**가 물을 OH⁻로 활성화해 CO₂를 공격(금속 이온 촉매의 예).

## 7. 탈수소효소의 의미
**출처** (10 · 헷갈리기 쉬운 효소 용어) ★★

- 이름은 "수소 제거"지만 핵심은 **전자**: 수용액에서 전자는 혼자 못 움직이고 **수소와 함께** 이동.
- 탈수소효소 = 기질의 전자를 (수소와 함께) **NAD⁺나 FAD로 전달**(역반응도 촉매).
- NAD⁺는 **하이드라이드(H⁻)**로 받음 → NADH. → 결국 ATP 생산으로 연결(Ch1 "전자 흐름").

## 8. 헷갈리는 효소 이름
**출처** (10 · 헷갈리기 쉬운 효소 용어, 효소의 분류) ★

- **신테이스(synthase)** ATP 불필요 / **신테테이스(synthetase)** ATP 사용.
- **포스파테이스** 물로 인산기 제거 / **포스포릴레이스** 무기 인산(Pi)으로 결합을 자름(가인산분해).
- **옥시데이스** O₂를 전자 수용체로만 사용 / **옥시제네이스** O 원자가 생성물에 들어감.
- 분류 7종: 산화환원·전이·가수분해·분해(lyase)·이성질화·연결(ligase)·자리옮김(translocase). 예: 헥소카이네이스 EC 2.7.1.1.
- 효소 이름 유래: 부흐너가 **세포 없는 효모 추출물**로 발효 → en(안) + zyme(효모).

# C. 반응 속도론과 저해 (요약)

## 9. 반응 속도론 요약
**출처** (11 · 미카엘리스-멘텐 ~ kcat/Km) ★

> 계산·그래프 단원이라 메커니즘 문서에서는 결론만 적습니다.

- **V₀ = Vmax[S] / (Km + [S])**, Km = (k₋₁ + k₂)/k₁. 가정: [E] ≪ [S], ES 정상 상태, 초기 속도.
- [S] = Km → V₀ = Vmax/2. k₂ ≪ k₋₁이면 Km ≈ Kd → **Km 낮을수록 친화도 높음**(항상은 아님).
- 라인위버-버크: 1/V₀ = (Km/Vmax)(1/[S]) + 1/Vmax, **x절편 −1/Km, y절편 1/Vmax**.
- **kcat = Vmax/[E]ₜ = 전환수**(카탈레이스 4×10⁷ s⁻¹). **kcat/Km = 특이성 상수**, 10⁸~10⁹ M⁻¹s⁻¹이면 확산 속도 한계의 **완벽한 효소**.
- 이기질 반응: **삼원 복합체**(ordered/random, 이중 역수 플롯 교차) vs **핑퐁(이중 치환, 평행선)**. 전정상 상태 속도론(산으로 반응 정지 후 측정).
- 영향 요인: 기질 농도(포화), 최적 온도, 최적 pH.

## 10. 가역적 저해의 결합 위치
**출처** (11 · 효소 저해) ★★

| 유형 | 저해제가 붙는 곳 | 겉보기 Vmax | 겉보기 Km | 이중 역수 플롯 |
|---|---|---|---|---|
| **경쟁적** | **활성 부위**(기질과 같은 자리, 경쟁) | 불변(기질을 많이 넣으면 이김) | 증가 | y절편에서 교차 |
| **불경쟁적** | **ES 복합체에만**, 기질 자리 아닌 곳 | 감소 | 감소 | 평행선 |
| **혼합형** | 다른 자리, **E와 ES 모두** | 감소 | 증가 또는 감소 | 축 밖 한 점 교차 |
| **비경쟁적** | 혼합형 중 α = α′ | 감소 | 불변 | x절편에서 교차 |

- 식: V₀ = Vmax[S] / (αKm + α′[S]).
- 경쟁적 저해의 실제 예: **오셀타미비르(타미플루)–뉴라미니데이스**(Ch7 문서).

# D. 비가역적 저해와 약물

## 11. DIFP
**출처** (11 · 비가역적 저해) ★★★

1. **DIFP(다이아이소프로필 플루오로인산)**가 **키모트립신 활성 부위 Ser195의 –OH**와 **공유 결합**.
2. Ser의 OH가 사라짐 → 촉매(친핵 공격) 불가 → 영구적 불활성.
- 원리: 비가역 저해제는 대개 **전이 상태와 비슷한 구조**로 설계(효소는 전이 상태에 가장 친화도가 높으므로).
- 〔보충〕 DIFP 같은 유기인산 화합물은 아세틸콜린에스터레이스의 활성 부위 Ser도 같은 방식으로 막는다(신경가스·살충제의 원리).

## 12. 자살 저해제 DFMO
**출처** (11 · 비가역적 저해) ★★★

1. **자살 저해제 = 기전 기반 불활성화제**: 그 자체로는 저해하지 못하고, **효소가 정상 촉매 작용으로 바꿔 준 결과물**이 효소를 비가역적으로 막음 → 효소가 스스로를 죽임.
2. **DFMO(다이플루오로메틸오르니틴)**: 플루오린 2개. 표적 **오르니틴 탈카복실화효소(ODC)** — **폴리아민** 합성 효소.
3. ODC가 DFMO를 "살짝 바꾸고" → 바뀐 DFMO가 ODC를 저해.
4. **선택 독성의 이유**:
   - **사람 ODC**: **전환(turnover)이 빠름** → 금방 새 효소가 만들어져 독성이 크지 않음.
   - **트리파노소마(아프리카 수면병 원충) ODC**: 전환이 느림 → 한 번 불활성화되면 회복이 안 됨 → 원충에 치명적.
5. → **아프리카 수면병 치료제**.

〔보충〕 ODC의 조효소는 PLP. 탈카복실화 후 생긴 반응성 중간체가 F⁻를 잃고 활성 부위 Cys와 공유 결합한다.

## 13. HIV 프로테에이스 저해제
**출처** (11 · HIV 프로테에이스 저해제) ★★★

1. HIV는 mRNA → 긴 **폴리단백질(polyprotein)** 하나를 만든 뒤 **잘라서** A·B·C 단백질을 만듦(효율).
2. 자르는 효소 = **HIV 프로테에이스** → 못 자르면 기능 단백질이 안 생김 → 주요 치료 표적.
3. HIV 프로테에이스는 **두 개의 아스파르트산(Asp)**으로 펩타이드를 자름.
4. 이 과정의 **전이 상태 화학 구조를 모방**한 약 = **인디나비르, 로피나비르**.
5. 공유 결합이 아니라 **전이 상태 유사체**로 결합하지만, 거의 공유 결합처럼 강해서 **사실상 비가역 저해제처럼** 작용.

〔보충〕 HIV 프로테에이스는 같은 소단위체 2개(이량체)의 **Asp25, Asp25′**가 활성 부위. 하나가 물을 활성화해 카보닐 탄소를 공격 → **사면체 중간체**. 약물은 이 사면체를 자를 수 없는 –CH(OH)– 구조로 흉내 낸다.

## 14. 코로나 치료제
**출처** (11 · 코로나바이러스 치료제, 교재 외) ★

- **프로테에이스 억제**: **팍스로비드**.
- **RNA 의존성 RNA 중합효소 억제**: **렘데시비르, 몰누피라비르** → 바이러스 RNA 증식 차단.

## 15. 페니실린과 β-락타메이스
**출처** (11 · 페니실린과 β-락타메이스 억제제), (12 Ch7 펩티도글라이칸) ★★★

1. 세균은 **펩티도글라이칸 세포벽**의 사슬 사이를 펩타이드로 **교차 결합**해야 함 → 효소 **트랜스펩티데이스**.
2. **페니실린**(구조: **β-락탐 고리**)이 기질 대신 들어가 **트랜스펩티데이스 활성 부위 Ser의 –OH와 공유 결합** → **비가역 저해** → 세포벽 약화.
3. **내성균**: **β-락타메이스**가 β-락탐 고리를 **분해** → 페니실린 무력화.
4. **클라불란산**: **β-락타메이스를 비가역적으로 저해**.
5. **오구멘틴 = 아목시실린(페니실린 계열) + 클라불란산** → 내성균까지 관리.

〔보충〕 페니실린의 β-락탐은 트랜스펩티데이스의 원래 기질 **D-Ala-D-Ala**의 구조를 닮았다(Ch3 D-알라닌과 연결).

# E. 효소 반응의 실제 예

## 16. 키모트립신의 반응 기전
**출처** (11 · 키모트립신) ★★★

**기본**: 소화 효소, **세린 프로테에이스**. **Phe, Trp, Tyr(고리 구조)의 C-말단 쪽 펩타이드 결합**을 자름.

**촉매 3인조(catalytic triad)**: **Ser195, His57, Asp102** — 서열상 멀리 떨어져 있지만 접힘으로 한곳에 모임.

**단계**
1. **기질 결합**: 방향족 곁사슬이 노란색 **소수성 포켓**에 쏙 들어감(안 맞으면 반응 안 함 → 특이성).
2. **세린 활성화**: 양성자가 없는 **His57**이 **Ser195 –OH의 H를 빼앗음**(탈양성자화) → Ser가 **O⁻**가 되어 친핵성 증가. (일반 염기 촉매)
3. **아실화**: Ser O⁻가 펩타이드 **카보닐 탄소를 공격** → Ser에 아실기가 붙음(**아실-효소 중간체**, 공유 결합 촉매) → **생성물 1(뒷부분, 아민 쪽)** 방출.
4. **탈아실화**: **물**이 들어오고 His가 다시 관여 → 아실-효소 결합이 끊어짐 → **생성물 2(앞부분, 카복실 쪽)** 방출 → 효소 재생.

**왜 His인가**: pKa ≈ **6.0** → 중성 pH에서 양성자를 받고 내놓을 수 있는 유일한 잔기 → 중성에서 일하는 효소들은 대부분 촉매 3인조에 His를 가짐.

〔보충〕
- **Asp102**는 His57의 양성자화된 고리를 정전기적으로 붙잡아 배향·pKa를 맞춰 줌.
- 4번 단계에서 His57은 이번엔 **물의 H를 빼앗아 OH⁻를 만들고**, OH⁻가 아실-효소의 카보닐을 공격.
- 3·4번 모두 **사면체 중간체**를 거치고, 그 O⁻는 **옥시음이온 구멍(oxyanion hole, Gly193·Ser195의 골격 N–H)**이 수소 결합으로 안정화(전이 상태 결합의 예).
- 전정상 상태 속도론에서 아실화가 빠른 "폭발기(burst)", 탈아실화가 느린 정상 상태로 관찰된다.

## 17. 키모트립신 최적 pH 8
**출처** (11 · 키모트립신의 최적 pH가 8인 이유) ★★★

**① pH가 너무 낮으면 안 되는 이유 — His57**
- His57은 Ser195의 H를 받아야 하므로 **양성자가 없는(unprotonated) 상태**여야 함.
- pH가 낮으면 His57에 미리 양성자가 붙어 일을 못함.

**② pH가 너무 높으면 안 되는 이유 — Ile16**
- 키모트립신은 **키모트립시노젠**(불활성 전구체)으로 만들어진 뒤 중간중간 잘려 성숙형이 됨 → 한 사슬의 **N-말단이 Ile16**.
- **Ile16의 α-아미노기가 양성자화(–NH₃⁺)** 되어 있어야 **Asp194(–COO⁻)와 염다리** → 활성 구조 안정.
- pH가 너무 높으면 Ile16의 양성자가 떨어져 염다리 불가 → 활성 구조 붕괴.

**→ 두 조건이 균형을 이루는 pH 8.0이 최적.**

〔보충〕 키모트립시노젠은 트립신이 Arg15–Ile16 사이를 잘라 활성화된다. Ile16–Asp194 염다리가 생기면서 기질 결합 포켓과 옥시음이온 구멍이 제자리를 잡는다.

## 18. 헥소카이네이스와 자일로스
**출처** (11 · 헥소카이네이스) ★★★

1. 헥소카이네이스: 글루코스를 활성 부위에 맞추고 **ATP로 6번 탄소에 인산기**를 붙임.
2. **자일로스**(탄소 5개, 글루코스에서 마지막 탄소 하나가 없음)도 활성 부위에 **딱 맞게 결합**.
3. 하지만 인산을 받을 **6번 탄소가 없음**.
4. → **ATP가 물과 반응해 무기 인산(Pi)만 생기고** 인산화는 안 됨 → ATP 낭비.
- 교훈: 결합(fitting)만으로 촉매가 되는 게 아니라 미세한 구조까지 맞아야 한다.

〔보충〕 교재에서 이 예는 **유도 적합**의 증거: 글루코스·자일로스가 결합하면 헥소카이네이스가 크게 닫히며 물을 배제하고 ATP를 정렬하는데, 자일로스로 닫힌 경우 그 자리에 들어온 물이 ATP를 가수분해한다.

## 19. 에놀레이스와 Mg²⁺
**출처** (11 · 에놀레이스) ★★★

1. 해당 과정 효소: **2-포스포글리세르산 → 포스포에놀피루브산(PEP)** (가역, **에놀** = C=C 탄소에 OH).
2. **Mg²⁺ 필수**: 양전하로 **반응 중간체의 음전하를 안정화** → 반응 진행. 없으면 반응 불가. (금속 이온 촉매)

〔보충〕 활성 부위에서 **Lys345**가 일반 염기로 C-2의 양성자를 떼어 **에놀레이트 중간체**를 만들고, Mg²⁺ 2개가 그 음전하를 안정화한다. 이어 **Glu211**이 일반 산으로 C-3의 OH를 양성자화해 물로 떠나게 한다(탈수).
