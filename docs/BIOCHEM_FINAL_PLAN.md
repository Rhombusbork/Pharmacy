## 4. 오답·키워드 제작 체계
### 4-1. 개념 진술(K1): 유기화학 4-1과 같은 축 분석·7가지 왜곡 기법
생화학 축(족보에서 추출):
| 축 | 묻는 것 | 족보 예 |
|---|---|---|
| B1 구성·구조 | 무엇으로 이루어졌나, 결합·위치 | 염기+오탄당+인산, C1′ β-N-glycosidic |
| B2 위치·분포 | 어디에 있나(막 면, 소기관, 조직) | apical SGLT, basal GLUT, 카디올리핀 미토콘드리아 내막 |
| B3 에너지·구동력 | 무엇이 밀어주나 | Na⁺/K⁺ 펌프가 Na⁺ 농도 유지, 화학+전기 퍼텐셜 |
| B4 조절·예외 | 무엇이 조절하나 / 안 하나 | 인슐린은 장 포도당 흡수를 **촉진하지 않음** |
| B5 수치·연도·인물 | 숫자·역사 | C→U 하루 100, 탈퓨린화 10,000, 2003 인간 유전체 |
| B6 질병·약물 연결 | 결핍·저해 → 결과 | 와파린 → 비타민 K, ATRA → 백혈병, Niemann-Pick |
생화학에서 특히 많은 왜곡: **T6 수치·순서 바꾸기**(피부→간→신장 순서, 지름 A>B>Z), **T7 사례 바꿔치기**(NAD vs ATP 리게이스, Dicer vs Cas9, syn vs anti), **T1 반대말**(왼손/오른손, 안쪽/바깥쪽, 증가/감소).

### 4-2. 서술형(K9~K11): 키워드 사슬 체계
1. 족보·교재 서술 주제마다 **모범답안을 키워드 사슬**로 쪼갠다(예: Na⁺/K⁺ ATPase = E1 상태 → 3Na⁺ 결합 → ATP로 **Asp** 인산화 → E2 전환 → 3Na⁺ 밖으로 → 2K⁺ 결합 → 탈인산화 → E1 → 2K⁺ 안으로 → 농도 구배·전기 구배 형성).
2. 5단계: 사슬의 빈칸 하나씩 객관식(오답 = 같은 사슬의 다른 키워드 + 비슷한 계열 단어).
3. 6단계: ① "다음 중 이 서술에 꼭 들어가야 할 키워드가 아닌 것은?" ② 서술 주관식(모범답안 + 채점 키워드 목록 → 사용자가 비교 후 맞은 걸로 처리).
4. 키워드마다 **점수 매기기 기준**(필수 / 있으면 좋음)을 해설에 표시.

### 4-3. 예측형(7단계, 사이트 P형)
"○○(독소·돌연변이·약물·유사체)를 처리하면 ○○(cAMP·Ca²⁺·막전위…)은?" — 오답은 ① 반대 방향 ② 다른 경로의 결과(Gs ↔ Gi ↔ Gq) ③ 상류만 바뀌고 하류 안 바뀜 ④ 변화 없음.

### 4-4. 검수

### 8-3. 형식(생약학과 다른 점)
생약학은 "생약 1개 = 카드 1장"이었지만, 생화학은 개념이 이어지는 흐름이라 **교재 절(소단원) 1개 = 블록 1개**로 쓴다.
```
■ 10.1 지방산 표기와 물성 ································ [★ 족보 4회]
표기    탄소수:이중결합수(Δ위치) · Δ = 카복실 쪽 C1부터 · ω = 메틸 끝부터
        ★ 아라키돈산 20:4(Δ⁵,⁸,¹¹,¹⁴) = ω-6 (20 − 14)
필수    리놀레산 18:2 ω-6 · α-리놀렌산 18:3 ω-3 — 사람은 Δ⁹ 너머 이중결합 못 만듦
        EPA 20:5 · DHA 22:6 = ω-3(생선)
물성    탄소수↑ → 녹는점↑ · cis 이중결합↑ → 꺾임 → 녹는점↓·유동성↑
        트랜스 = 곧은 사슬 → 포화지방처럼 행동 → LDL↑ HDL↓
🎙      "18:2·18:3 필수지방산 계속 나오니 외워 두라" · "ω-6 나쁨·ω-3 좋음이 아니라 둘 다 필요"
함정    EPA·DHA를 ω-6로 / "사람은 어느 위치에나 이중결합" (전칭 과장)
```
- 기호: ★ = 족보 사실(횟수), 🎙 = 강의 강조(녹음이 있는 단원만), ⚠ = 녹음·교재 확인 부족, 함정 = 개념 진술 덱에서 쓴 왜곡
- 줄임: 문장 대신 명사형 · ↑↓→ · 영어 용어는 괄호 없이 그대로(예: N-β-glycosidic) · 구조식은 그림 대신 이름·약어·결합 위치로
- 앱은 `**굵게**`를 안 쓰지만 이 정리는 마크다운 파일이라 써도 됨

## 9. 축별 학습 (2026-11-08 사용자 지시)
> "한 축으로 개념을 나누고 그 안의 구분만 익히고 싶다. 용어 카드는 여러 축을 한 번에 외우게 한다. 먼저 경로에서 A 다음에 오는 것 하나씩만, 해설엔 전체 경로. 그 다음 NADH·ATP 문제를 챕터별로. 지금까지 만든 덱은 저장만 하고 Pages에는 족보만."

### 9-1. 원칙
- 한 문제 = **한 축의 한 칸**만 묻는다. 오답도 **같은 축·같은 사슬**에서만 고른다(다른 축의 지식으로 풀리지 않게).
- 해설 = 사슬(또는 표) 전체. 문제는 좁게, 해설은 넓게.
- 순서: 축별 기초(1층) → 두 축 연결(2층) → 기존 통합 덱(3층: 개념 진술·예측·비교·서술).
- 표시: 족보 덱 + 축별 덱만 `decks/index.json`에 둔다. 나머지 24덱은 `decks/index-hidden.json`에 목록만 옮겨 둠(파일·기록 그대로). 3층 단계에서 다시 올린다.

### 9-2. 냉정한 범위 판단
- 기말 범위 Ch7~12는 **대사 경로 장이 아니다**(해당과정·TCA·β-산화는 Ch14 이후). 그래서 "NADH·ATP가 생기나/쓰이나" 축은 문자 그대로는 거의 없다.
- 대신 장마다 같은 역할을 하는 **"에너지·전달자 축"**으로 바꾼다(아래 표). Ch8은 이 축이 거의 없어 건너뛰거나 아주 작게 한다.
- "다음 단계" 축은 Ch12(신호 경로)에서 가장 잘 맞고, Ch8·Ch9는 **과정 사슬**(손상 기전·Sanger·PCR·클로닝)로, Ch7·Ch10·Ch11은 사슬이 짧아 "대응(짝 맞추기)" 축 비중이 크다.
- 축 덱만으로는 서술형(왜?·통합)을 못 푼다 → 2층·3층이 반드시 필요.
