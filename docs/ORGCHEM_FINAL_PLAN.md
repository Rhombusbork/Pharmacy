## 4. 오답 선지 제작 체계

### 4-1. 개념 진술형(E): '축(axis)' 분석 → 개념어 교체 → 왜곡 기법

**① 족보 문항을 축으로 분해한다.** 5개 보기는 서로 다른 '물어보는 축'을 하나씩 맡는다.

반응형 축(말론산 23-3, 고리화첨가 25-21, TECA 24-7에서 추출):
| 축 | 묻는 것 |
|---|---|
| R1 활성 자리·수치 | 반응하는 자리가 어디고 왜 활성인가(pKa, 산성 H, 오비탈) |
| R2 메커니즘·기질 범위 | 친핵체/친전자체 역할, SN2/협동 등, 쓸 수 있는 기질(1차 RX 등) |
| R3 반복·선택성 | 몇 번 반응하나, 어느 위치·입체로 가나 |
| R4 핵심 단계의 필요조건 | 반드시 필요한 구조·조건(β-카보닐, s-cis, 빛) |
| R5 응용·생성물 범위 | 무엇을 만들 수 있고 없나(고리형, 1차 아민만 등) |

시약형 축(LDA 23-2에서 추출):
| 축 | 묻는 것 |
|---|---|
| S1 정체 | 구조, 산–염기 관계(짝염기), pKa |
| S2 물성 | 용해도, 상태, 안정성 |
| S3 구조 → 반응성 인과 | 입체장애 → 비친핵성 등 |
| S4 조건 | 온도, 용매, 당량, 처리 순서 |
| S5 선택성·용도 | 어떤 생성물/선택성을 위해 쓰나 |

**② 반응·시약을 바꿀 때 개념어 교체표를 만든다.** 같은 축에 들어갈 새 반응의 개념어를 칸마다 채운다. 채울 수 없는 축이 있으면 그 반응의 고유 축으로 바꾼다(예: 페리고리 반응은 '반복' 대신 '열/빛 조건').

**③ 각 축마다 '옳은 문장'과 '틀린 문장'을 한 쌍으로 만든다.** 틀린 문장은 아래 기법 중 하나로만 만들고, 어떤 오개념을 노리는지 해설에 적는다.

| 왜곡 기법 | 족보 실례 |
|---|---|
| T1 반의어 뒤집기 | 짝염기↔짝산, 친핵체↔염기, 속도론적↔열역학적, α↔β, SN2↔SN1, 동일↔반대 방향, 동일면↔반대면, cis↔trans, 짝수↔홀수 |
| T2 필요조건 부정 | "β 위치에 카보닐기가 반드시 있지 않아도 가능하다" |
| T3 전칭 과장 | "항상 케토 쪽으로", "예외없이 모두 적용" |
| T4 그럴듯한 틀린 인과 | "이온성 화합물이므로 유기용매에 녹지 않는다", "산소가 더 친핵성이기 때문" |
| T5 가능↔불가능 뒤집기 | "덜 치환된 엔올 음이온은 만들 수 없다", "고리형 카복실산 합성에 적절하지 않다", "열적 [2+2]로 사이클로뷰테인 생성" |
| T6 수치·범위 바꾸기 | pKa 13 ↔ 25, 1차 RX ↔ 3차 RX |
| T7 사례 바꿔치기 | 맞는 원리 + 틀린 구체 사례(열적 [2+2]) |

**④ 조립 규칙**
- '틀린 것 고르기': 옳은 문장 4개 + 틀린 문장 1개. '옳은 것 고르기': 옳은 1개 + 틀린 4개(서로 다른 기법으로).
- 5개 보기는 반드시 **서로 다른 축**을 맡는다. 같은 축이 두 번 나오지 않는다.
- 보기 길이·말투를 비슷하게 맞춘다(길이로 정답이 보이지 않게).
- 틀린 문장은 앞부분이 맞고 뒷부분(이유·조건)만 틀린 '반쯤 맞는' 형태를 기본으로 한다.
- 해설은 5개 보기를 모두 설명하고, 오답이 왜 그럴듯한지(노리는 오개념)를 적는다.
- 같은 축 쌍 은행에서 '틀린 것' 버전과 '옳은 것' 버전을 둘 다 만들 수 있게 저장한다.

### 4-2. 구조 보기(A·B·C 유형): 구조 오답 생성 규칙
| 코드 | 오답 | 예 |
|---|---|---|
| X1 | 중간체에서 멈춤 | 에스터+LiAlH₄ → 알데하이드, Robinson → 마이클 생성물 |
| X2 | 과반응/덜 반응 | Grignard 1당량만 첨가된 케톤, 2번 알킬화 |
| X3 | 위치 이성질체 | 속도론적↔열역학적 엔올 음이온 위치, Markovnikov 반대 |
| X4 | 입체 이성질체 | cis↔trans, endo↔exo, E↔Z |
| X5 | 탄소·고리 수 착오 | 고리 크기 ±1, RCM에서 에틸렌을 빼지 않음 |
| X6 | 다른 경로 결과 | 1,2- vs 1,4-첨가, SN2 vs E2, 이민 vs 엔아민 |
| X7 | 작용기 혼동 | 아마이드 vs 아민, 아세탈 vs 헤미아세탈 |
보기 4~5개 중 오답은 서로 다른 X 코드를 쓴다.

### 4-3. 검수
1. 모든 SMILES를 RDKit로 검사(scratchpad venv)한다.
2. 각 문항에 '노리는 오개념' 메모가 있는지 확인한다.
3. 세트별로 정답 보기가 가장 길거나 가장 자세한 경우가 몰리지 않았는지 확인한다.
4. 사용자가 세트를 풀고 피드백하면 반영한다.

## 5. 개념 진술 예시 (족보 23-3 말론산 → Gabriel 합성)

(대화에서 사용자에게 보여준 것과 같은 내용 — 승인 후 이 방식으로 진행)

| 축 | 말론산 에스터 합성(족보 원문) | 개념어 교체 → Gabriel 합성 (옳은 문장) | 틀린 문장(기법) |
|---|---|---|---|
| R1 | 두 카보닐 사이 알파수소의 산성도가 크다(pKa 13) | 프탈이미드의 N–H는 두 C=O 사이에 있어 산성이 크므로(pKa 약 8) KOH로도 떼어낼 수 있다 | …N–H는 산성이 약해(pKa 약 36) LDA가 필요하다 (T6) |
| R2 | 엔올음이온이 친핵체, 1차 RX와 SN2 | 프탈이미드 음이온이 친핵체로 1차 RX와 SN2 반응한다 | …3차 RX와 SN1 반응한다 (T1·T6) |
| R3 | α-H 2개 → 두 번 연속 | N에 H가 하나뿐이고 생성물은 친핵성이 없어 한 번만 알킬화되므로 과알킬화가 없다 | …생성물이 다시 알킬화되어 2차·3차 아민 혼합물이 생긴다 (T5 — 말론산의 '두 번 가능' 논리를 그대로 옮긴 함정) |
| R4 | 탈카복실화는 β-카보닐이 반드시 필요(오답: 없어도 가능) | 아민을 얻으려면 마지막에 가수분해(또는 하이드라진 분해)로 프탈산 부분을 떼어내야 한다 | …SN2 직후 바로 1차 아민이 얻어지므로 가수분해 단계는 반드시 필요하지는 않다 (T2) |
| R5 | 다이할라이드로 고리형 카복실산 가능 | 생성물은 1차 아민뿐이며, 아릴 할라이드로는 아닐린을 만들 수 없다 | …아릴 할라이드를 쓰면 아닐린도 합성할 수 있다 (T7) |

## 6. 경향성·비교(G·J) 챕터별 필수 목록

- **Ch20**: 하이드라이드 환원제 세기·선택성 표, 카보닐의 유기금속 반응성(알데하이드 > 케톤 > 에스터), RMgX 1,2 vs R₂CuLi 1,4, 유기금속이 파괴되는 작용기(OH, NH, COOH, 말단 알카인)
- **Ch21**: 알데하이드 vs 케톤 반응성(입체·전자), 수화 평형 크기(클로랄·HCHO·아세톤), IR C=O 위치(콘쥬게이션·고리 크기), 이민 pH 의존성, 가역/비가역 친핵체
- **Ch22**: 반응성 RCOCl > (RCO)₂O > RCOOH ≈ RCOOR' > RCONR₂, 이탈기 염기도, IR C=O 순서, 카복실산 산성도(EWG 수·거리), 변환 가능 개수("가장 적은 종류의 생성물을 만드는 유도체")
- **Ch23**: α-H pKa(1,3-다이카보닐 9~13, 케톤 20, 에스터·나이트릴 25, 아마이드 30), 엔올 함량, D 치환 개수, 속도론적/열역학적 엔올 음이온 자리·조건, 염기 선택(짝산 pKa 비교)
- **Ch24**: 자기 알돌 가능 여부(α-H), 주개/받개 전용, 분자 내 고리 크기(1,4 → 5원, 1,5 → 6원, 1,6-다이에스터 → 5원), 교차 생성물 개수, 알돌·Claisen 생성물 종류 차이
- **Ch25**: 염기도(알킬 > NH₃ > 아릴 > 아마이드, sp³ > sp² > sp, 피롤 최약, 치환기 효과), 끓는점(1차 > 2차 > 3차), Hofmann vs Zaitsev, 카이랄 질소(반전 vs 4차 암모늄)
- **Ch26**: 짝지음 가능한 할라이드, 입체 보존 여부, RCM 고리 크기, 반응별 촉매(Pd/Zn(Cu)/Ru)
- **Ch27**: 열/빛 × 전자쌍 짝/홀 → 회전 방향·면 표, HOMO 판정, 생성물 cis/trans, endo/exo, Cope 평형 방향, 반응 분류(전자고리화/고리화첨가/시그마), [i,j] 표기
