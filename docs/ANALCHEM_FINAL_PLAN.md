## 3. 오답 제작 체계

### 3-1. 진술형: 축 → 개념어 교체 → 왜곡 기법(QUIZ_PLANNING_METHOD 2-1)
분광 과목에서 자주 쓰일 짝(반의어·바꿔치기) 사전:
| 축 | 바꿔치기 짝(T1·T7) |
|---|---|
| 광원 | UV = 중수소(D₂)등 ↔ Vis = 텅스텐(할로겐)등 ↔ 형광 = 제논 아크 ↔ AAS = 중공음극램프 ↔ IR = Nernst·Globar |
| 셀 재질 | UV = 석영 ↔ Vis = 유리 가능 ↔ IR = NaCl·KBr(유리·석영 ✗) ↔ 형광 = 사면 투명 석영 |
| 배치 | 흡광 = 광원–시료–검출기 일직선 ↔ 형광·Raman = 직각 |
| 파장선택기 | UV-Vis 1개 ↔ 형광 2개(여기·방출) |
| 스펙트럼 | 원자 = 선 ↔ 분자 = 띠, 흡수–형광 = 거울상 |
| 전이 | σ→σ* 가장 큰 에너지(<200 nm) ↔ n→π* 가장 작은 에너지(R-band, 약함) ↔ π→π*(K-band, 강함) |
| 이동 | 장파장(bathochromic, 적색) ↔ 단파장(hypsochromic, 청색), 농색 ↔ 담색 |
| 진동 | 신축(높은 파수) ↔ 변각(낮은 파수), 결합 차수↑·k↑ → 파수↑, 환원질량↑ → 파수↓ |
| IR/Raman | IR = 쌍극자 변화 ↔ Raman = 분극률 변화, Stokes(강함) ↔ anti-Stokes(약함) |
| NMR | 차폐(upfield, 낮은 δ) ↔ 탈차폐(downfield, 높은 δ), ppm = 자기장 무관 ↔ Hz = 자기장 비례, 활성 핵(I ≠ 0: ¹H·¹³C·¹⁵N·¹⁹F·³¹P) ↔ 비활성(¹²C·¹⁶O·³²S) |
| 원자분광 | 냉증기 = Hg ↔ 수소화물 = As·Se·Sb, 해방제 = La·Sr ↔ 이온화 억제 = Cs·K, AAS(흡수) ↔ AES·ICP(발광) |
- T6 수치: 파장 범위(UV 200–400, Vis 400–800 nm, IR 2.5–25 μm = 4000–400 cm⁻¹), δ 범위(카복실산 10–12, 알데하이드 9–10, 방향족 6.5–8, 알킬 0.9–1.5)
- T4 인과: "대칭 결합이라 IR 흡수가 강하다", "농도가 높을수록 Beer 법칙이 더 잘 맞는다"

### 3-2. 계산형: 실수 코드로 오답 만들기
| 코드 | 실수 | 예(Beer–Lambert) |
|---|---|---|
| C1 | %T를 소수로 안 바꿈·log 대신 ln | A = −log 32.9 |
| C2 | 셀 길이·단위(cm·mm, g/L·mg/mL) 누락 | b = 2 cm를 1로 |
| C3 | 희석 배수 한 단계 빠뜨림·거꾸로 | 300 mL → 10 → 50 mL 중 하나 누락 |
| C4 | ε ↔ E¹%₁cm 혼동(×10/분자량) | |
| C5 | Hooke: 환원질량 대신 한 원자 질량, k 단위(dyn/cm ↔ N/m) | |
| C6 | NMR: Hz를 자기장과 무관하게 둠 / ppm을 자기장에 비례시킴 | |
보기 5개 중 오답은 서로 다른 코드로 만들고, 해설에 계산 과정 + 각 오답의 실수를 적는다.

### 3-3. 해석형(스펙트럼·구조)
- IR: 작용기 표(O–H 3200–3550 넓음, C–H 2850–3000, C≡N·C≡C 2100–2260, C=O 1650–1750, C=C 1600–1680, 지문 영역 < 1500) → 오답은 이웃 영역 작용기
- ¹H NMR: 구조 SMILES(RDKit 검증) → 신호 수·n+1·적분비 계산을 스크립트로 → 오답은 "등가 수소를 따로 셈", "n이 아니라 n+1 누락", "적분비 뒤집기"
- 종합: MS 분자량·조각 + IR 띠 + NMR 신호를 모두 만족하는 구조 1개 + 하나씩 어긋나는 구조 4개

## 4. 예시 (aa → bb)
**aa = 족보 UV-Vis 기기 진술(2022-2 #5 · 2023-2 #5 · 2024-2 #5·16 · 2025-2 #6)** 축 분해:
| 축 | 족보 보기(정리) | 판단 |
|---|---|---|
| 광원 | 가시부 광원은 중수소등·수은등 | ✗ (가시부 = 텅스텐, 중수소 = 자외부) |
| 광도계 형식 | 겹살형(복광속) 광도계는 광원이 2개 필요 | ✗ (광원 1개, 빛을 둘로 나눔) |
| 셀 재질 | 가시부 측정에는 경질유리·석영 셀 | ○ |
| 셀 재질(자외) | 자외부는 석영 셀 | ○ |
| 검출 | 흡광도는 농도·광로 길이에 비례 | ○ |
→ **bb = 형광광도계** (같은 5축):
| 축 | 옳은 문장 | 틀린 문장(기법) |
|---|---|---|
| 광원 | 광원으로 제논 아크램프를 쓴다 | …텅스텐등을 쓴다 (T7) |
| 파장선택기 | 여기·방출용 파장선택기가 2개 있다 | …1개만 있다 (T6) |
| 셀 재질 | 사면이 투명한 석영 셀을 쓴다 | …두 면만 투명한 유리 셀을 쓴다 (T7) |
| 배치 | 검출기는 입사광과 직각 방향 | …입사광과 일직선 (T1 — 흡광도법과 혼동) |
| 세기 | 묽은 농도에서 형광 세기는 농도에 비례 | 농도가 높을수록 형광 세기가 계속 커진다 (T3 — 자체 소광 무시) |

## 5. 검수
- 정답 근거: 강의자료(받으면) > 대한약전 일반시험법(자외가시부·적외부·원자흡광·형광·선광도·NMR) > 표준 기기분석 지식. 근거가 강의자료가 아니면 해설에 ⚠
- 계산 문항은 스크립트로 정답·오답 값을 계산(손계산 금지), 유효숫자 일관
- 구조식은 RDKit, ¹H 신호 수는 RDKit 대칭 클래스로 확인
- 족보 원본 덱은 작성자 이름·학번 없이 "외부 정리본"으로만 표기
- 덱 검사 → 앱 스크린샷 → 커밋·push

## 6. 사용자에게 받을 것·물을 것
1. **기말 강의자료(9~14강 분광 PPT)** — 교재가 분광을 다루지 않아 가장 필요. 없으면 족보 + 대한약전 + 표준 지식으로 만들고 ⚠ 표시
2. **질량분석(7주)** 이 기말에 포함되는지 — 2024-2·2025-2 기말에는 MS가 5~7문항씩 나왔음
3. **선광도·CD(편광)** — 2020~2023에는 매년, 2024 이후는 출제 없음. 올해 9~10주에 배웠는지
4. 계산 문제 비중(Beer–Lambert·Hooke·NMR 계산을 별도 덱으로 크게 할지)
