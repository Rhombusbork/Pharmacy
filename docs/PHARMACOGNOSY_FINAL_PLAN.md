## 2. 핵심 설계: "생약 카드 → 카드 문제 → 유형별 문제"
(2026-11-03 사용자 결정) **자료는 요약집 + 족보를 기본으로, 교재는 빈칸만 채운다.** 그리고 **카드를 먼저 만들어 카드 자체로 문제를 낸 뒤** 다른 유형으로 넓힌다.

### 2-1. 자료 우선순위
| 순위 | 자료 | 쓰는 곳 |
|---|---|---|
| 1 | 요약집(대표 생약 약 45개 카드: 기원·과명·성분·약리·확인시험·응용·주의) | 카드 본문 |
| 2 | 족보 7개년(시험에 실제 나온 사실: 지표성분 함량, 산지, 한자, 법제, 독성…) | 카드에 덧붙임 + ★표시 |
| 3 | 교재 스캔(p97–386) | 요약집에 없는 생약(약 95개)과 족보 사실의 확인만 — 필요한 쪽만 이미지로 읽음 |
| 4 | 학명 OCR 깨짐 | 교재·일반 지식으로 바로잡음(예: Ang이icae → Angelicae) |

### 2-2. 카드 필드
한글명 · 라틴 생약명 · (한자) · 기원(국명 + 학명, 약용부위) · 과명(한글·라틴) · 성분(계열: 대표 성분) · 지표성분·함량(약전) · 약리 · 응용(효능·적응증) · 확인시험 · 주의(독성·금기·법제) · 산지 · 관련·동류 생약 · 족보 ★(나온 연도)
- 요약집·교재에 없는 칸은 비워 두고 문제를 만들지 않는다.
- 카드 데이터는 `../.tools/pg/cards/` 에 범위(주차)별 파이썬 파일로 둔다.

### 2-3. 카드 문제(1차 덱) — 카드 자체를 보고 푸는 문제
| 코드 | 형식 | 오답 |
|---|---|---|
| C1 이름 가린 카드 | 카드에서 이름·라틴명·기원·관련 생약(정답이 바로 보이는 칸)을 가리고 "이 카드의 생약은?" | 같은 범위의 이웃 생약 4개(같은 과·같은 성분 계열·비슷한 효능) |
| C2 칸 가린 카드 | 카드를 다 보여 주고 한 칸만 ( ㉠ )로 가려 "㉠에 들어갈 것은?" — 생약마다 중요한 칸 3~5개 | 이웃 생약의 같은 칸 |
| C3 카드 주관식 | 이름 → 지표성분·과명·대표 성분 쓰기(맞은 걸로 처리 가능) | — |
해설에는 항상 **완성된 카드 전체**를 보여 준다 → 문제를 풀수록 카드를 반복해서 보게 된다.

### 2-4. 오답 고르는 규칙(헷갈리는 이웃)
| 묻는 칸 | 오답 후보 |
|---|---|
| 과명 | 같은 범위에서 자주 나오는 과(콩과·미나리과·미나리아재비과·꿀풀과·백합과·생강과·가지과) + 이름이 비슷한 과(Rubiaceae ↔ Rutaceae, Polygonaceae ↔ Polygalaceae) |
| 성분 | 같은 계열 성분(protoberberine끼리, chromone끼리, sesquiterpene끼리) + 같은 과 생약의 성분 |
| 생약 | 같은 과·같은 약용부위·이름 비슷(방풍↔해방풍, 창출↔백출, 지황↔숙지황, 천오↔초오↔부자) |
| 효능 | 같은 효능군의 다른 생약, 반대 효능(발한 ↔ 지한) |
| 학명 | 같은 속(Angelica gigas/acutiloba/sinensis, Atractylodes japonica/lancea/chinensis/macrocephala, Polygonatum 4종) |
| 확인시험 | 성분 계열별 반응(LB = 스테로이드·트라이터펜, Vitali = 트로페인, Bornträger = 안트라퀴논, FeCl₃ = 페놀·탄닌 등) |

## 3. 제작 순서 (2026-11-04 수정: 족보 빈출 변형을 최우선으로)
> 사용자 판단(2026-11-04): "족보에 자주 나오는 것들을 다양한 변형 문제로 내 주는 게 제일 중요." 교재 내용도 포함하되 비중은 족보 빈출 > 족보 1회 > 교재만.

| 단계 | 내용 | 형식 |
|---|---|---|
| **1·2** | 생약 카드 + 카드 문제 C1·C2·C3 (범위 전체를 한 번 훑는 기초, 9~14주) | 카드 그대로 |
| **3** | **족보 빈출 변형(최우선, 가장 많은 문항)** — 3-1장 | 객관식 + ㄱㄴㄷ + 주관식 |
| **4** | 족보 7개년 원본 덱(답은 카드로 판단, 불확실하면 ⚠) | 기존 족보 방식 |
| **5** | 유형별 드릴(구간 섞기, G1~G9) — 빈출 ★ 항목을 2~3배 더 자주 출제 | 객관식 |
| **6** | 비교·묶음: 동류 생약 차이(G10), 효능군 "아닌 것"(G11), 과별 분류(G12) | 객관식 + ㄱㄴㄷ |
| **7** | 함정 진술 5지(족보 22번 건강형) — 4장 체계, 빈출 생약부터 | 개념 진술 |
| **8** | 구조식 → 성분 → 생약·계열(G13) / 표 빈칸·처방(G14·G15) | SMILES + 주관식 |

### 3-1. 족보 빈출 변형 만드는 법
1. 족보 7개년에서 **사실 단위**(예: "향부자 ↔ cyperene", "부자 법제 → aconine")로 쪼개고, 나온 연도 수를 센다 → 빈출 표(★★★ 3회 이상 / ★★ 2회 / ★ 1회).
2. 빈출 사실 하나마다 **변형 4~6개**를 만든다(같은 사실을 다른 방향·형식으로):
   | 변형 | 예(부자 aconitine 진통 순서) |
   |---|---|
   | V1 정방향 | 진통 작용이 가장 강한 것은? → mesaconitine |
   | V2 역방향 | mesaconitine을 함유한 생약은? → 부자(오답 천오·초오·백두옹·위령선 — 같은 과) |
   | V3 순서·짝 | 진통 순서로 옳은 것(족보 원형) / 부정맥 순서와 헷갈리게 |
   | V4 ㄱㄴㄷ 모두 고르기 | 부자에 대한 설명 — 법제·강심 성분·자근/모근·Mayer 시약 |
   | V5 아닌 것 | 부자의 효능이 아닌 것(족보: 이뇨) |
   | V6 주관식 | 법제하면 생기는 저독성 물질은? → aconine |
3. 오답은 2-4장의 "헷갈리는 이웃" + **족보에서 실제로 쓰인 오답 보기**를 우선 재사용한다.
4. 해설에 ★ 횟수와 연도(예: ★★★ 2021-2·2023-1·2025-2)를 적는다.
5. 교재에만 있는 내용은 1·2단계 카드와 5단계 드릴로 다루고, 변형 세트에는 넣지 않는다.

### 3-2. 남은 카드(12~14주) 만드는 방식 (2026-11-04, 토큰 절약)
- 요약집에 있는 생약 → 요약집 글자 + 족보 사실로 카드 작성(교재 안 읽음).
- 요약집에 없는 생약 → 교재 그 생약의 **첫 1~2쪽(기원·지표·성분·응용)만** 낮은 해상도로 확인. 참고문헌·성상 쪽은 건너뜀.

## 4. 함정 진술 체계 (6단계)
생약 진술의 축(족보 2025-2 22번 '건강'에서 추출):
| 축 | 묻는 것 | 건강 원문 |
|---|---|---|
| H1 가공·변화 | 수치·법제로 성분이 어떻게 변하나 | 건조 과정에서 shogaol 증가 |
| H2 동류 비교 | 비슷한 생약과 효능 차이 | 건강이 생강보다 발한 효과가 크다(틀림 — 생강이 발한) |
| H3 약리 | 생리 작용 | 담즙 분비↑, 구토 억제(멀미·임산부) |
| H4 특수 활성 | 항암·독성 등 | 항암 효능 |
| H5 기타 약리 | 진정·진통·혈압 등 | 진정·진통·혈압강하·위운동 억제 |
틀린 문장은 유기화학 7기법 그대로(특히 **T7 사례 바꿔치기**: 동류 생약과 맞바꾸기, **T1 반의어**: 증가↔감소, 발한↔지한).
