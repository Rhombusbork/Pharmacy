# 12단계 점검표: 일부러 망가뜨려 보기

각 항목마다 **① 망가뜨리기 → ② 저장(Ctrl+S) 후 브라우저 강력 새로고침(Ctrl+Shift+R) → ③ 기대 결과 확인 → ④ 되돌리기** 순서로 합니다.
결과 칸에 ✅(기대대로) / ❌(다름)을 적고, ❌이면 무엇이 보였는지 메모해 주세요.

## 시작 전 준비 (꼭!)

1. 홈에서 **"기록 내보내기"** 를 눌러 백업 파일을 받아 둡니다. (E 항목에서 기록을 망가뜨리기 때문)
2. 되돌리는 방법 두 가지:
   - 파일을 고친 직후라면: VS Code에서 **Ctrl+Z** 로 되돌리고 저장.
   - 헷갈리면: VS Code 터미널(Ctrl+`)에서 `git restore .` → 모든 파일이 마지막 커밋 상태로 돌아갑니다.
3. 한 번에 **한 항목만** 망가뜨리고, 확인 후 되돌린 다음 다음 항목으로 넘어갑니다.

> 아래에서 "02 덱"은 `decks/orgchem/02-structures.json` 입니다.

E3 에 입력할 것 (기록을 일부러 깨뜨림):
```
localStorage.setItem("quizapp:v1", "{깨진데이터")
```

E5 에 입력할 것 (기록 안에 깨진 항목 하나 끼워 넣기):
```
const d = JSON.parse(localStorage.getItem("quizapp:v1")); d.sessions.push(null); localStorage.setItem("quizapp:v1", JSON.stringify(d));
```

> Console에 붙여넣기가 막혀 있으면, 먼저 `allow pasting` 을 입력하고 Enter 한 뒤 다시 붙여넣으세요.

## 끝나면

1. `git status` 가 "nothing to commit" 인지(모두 되돌렸는지) 확인. 아니면 `git restore .`
2. `js/vendor/smiles-drawer.min.js` 이름이 원래대로인지 확인.
3. 홈에 경고가 하나도 없는지 확인.
4. ❌ 항목과 D1 에 대한 의견을 알려주시면 고칩니다.
